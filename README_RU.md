[README.md](README.md) — актуальная главная страница: возможности, установка,
локальная панель на порту **8787**, выбор версии и ограничения.

Исходники предварительного выпуска **`v0.18.2-rc.3`** с исправленным DC1.
Опубликованный `rc.2` выявил преждевременный откат обновления до завершения
восстановления VLESS. `rc.3` исправляет ожидание без ослабления проверок;
[аппаратная приёмка нового кандидата](docs/releases/0.18.2-rc.3.md) учитывается отдельно.
Обычный bootstrap по-прежнему устанавливает **latest stable `v0.18.0`**;
выбор кандидата описан отдельно и требует опубликованных файлов его версии.

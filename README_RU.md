# RAZVILKA — русская документация

[README.md](README.md) — возможности, установка, локальная панель на порту
**8787**, выбор стабильного или тестового выпуска.

Опубликован [v0.18.2-rc.4](https://github.com/ArtixSx/RAZVILKA/releases/tag/v0.18.2-rc.4).
На Netcraze aarch64 проверены обновление, перезапуск и фактический TUN-путь
свежих клиентских соединений в обычном и отдельном маркированном сценарии.
[Результаты и ограничения](docs/releases/0.18.2-rc.4-validation.md).
У rc.3 обычный TUN-путь работал, но условный конфликт с ранней политикой другого
VPN потребовал исправления. [Предупреждение rc.3](https://github.com/ArtixSx/RAZVILKA/releases/tag/v0.18.2-rc.3).

Обычный bootstrap устанавливает **latest stable `v0.18.0`**;
команда для нового тестового выпуска отдельно приведена в README.

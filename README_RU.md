# RAZVILKA

**Универсальный multi-engine routing hub для Keenetic / Netcraze + Entware.**

RAZVILKA объединяет разные способы маршрутизации и обхода ограничений в одном локальном Web UI: NFQWS2, usque/MASQUE, WARP WireGuard, sing-box, Xray, AmneziaWG и будущие адаптеры.

Главная идея — пользователь выбирает **сервис** (например YouTube, Discord или ChatGPT), а RAZVILKA отделяет этот выбор от конкретного **движка**, проверяет доступные пути и в дальнейшем сможет автоматически выбирать рабочий маршрут на основе реальных проверок.

> Текущий статус: **v0.0.7-control-lab / Safe Mode**. Активные изменения firewall/DNS/policy routing пока заблокированы по умолчанию. Config Center, черновики, валидация, диагностика и текущие HTTP-пробы уже работают.

## Основные принципы

- Service-first UI: сервисы отдельно, движки отдельно.
- Desired / Planned / Applied / Observed состояния не смешиваются.
- Никаких выдуманных результатов тестов или соединений.
- Проверка конфига до применения.
- Атомарное применение и будущий rollback.
- LAN-only интерфейс по умолчанию.
- Секреты не должны попадать в браузер или GitHub.
- Каждый движок подключается через отдельный адаптер.
- Уже существующие маршруты через внешние туннели учитываются как возможное искажение CURRENT-тестов.

## Проверка проекта

```sh
./scripts/check.sh
```

Проверяются Go tests/vet, shell/JavaScript syntax, а также сборки для amd64, arm64, mips и mipsle.

## Лабораторная установка Entware

В исходном checkout с GitHub скомпилированные бинарники не хранятся. Сначала собери их:

```sh
./build.sh
./scripts/lab-bootstrap.sh
```

GitHub Releases будут собирать и публиковать бинарники автоматически. Bootstrap устанавливает только Manager в Safe Mode и выполняет preflight до и после установки. Движки обхода автоматически не активируются.

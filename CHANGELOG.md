# Changelog

## 0.20.0

- Новая чистая база: настройки и данные отдельно (`/opt/etc/razvilka`, `/opt/razvilka`), журналируемые обновления 0.20+ с откатом. Переход с 0.19.3 и старее — через удаление старой версии и чистую установку.
- Обход только для включённых сервисов; исключения устройств и сайтов сильнее любых правил; всё остальное идёт обычным маршрутом роутера.
- Сервисы, заданные доменами, больше не превращаются в IP-маршруты через VPN или прокси (это перехватывало чужие сайты на общих IP): для них используется NFQWS2, который проверяет имя сайта в каждом соединении.
- «Сайты без обхода» работают в основном режиме: NFQWS2 не обрабатывает исключённые сайты и адреса, исключённый сервис не получает обхода; пересечение исключённого адреса с сетями сервиса через VPN или прокси останавливает применение с объяснением. Правки стандартного exclude.list в расширенных настройках NFQWS2 теперь действительно применяются.
- Сервис «Telegram · через VPN или прокси» в каталоге: только официальные IP-сети Telegram для VLESS, WireGuard или WARP.
- Автопилот не уходит в бесконечные повторы: недоступный в текущем режиме выбор показывается с причиной и действием.
- Простой режим панели по умолчанию; расширенный — переключателем. Для обычного редактирования не требуется отдельная разблокировка; защита восстановления и журнал сетевых операций сохранены.
- Удаление с переносом данных (`--uninstall --purge`) для повторной установки с нуля; установщик не ставится поверх версии до 0.20.
- Совместимость с Keenetic: iproute2 без -N, правила прошивки в RPDB, медленные USB-накопители; прерванный откат больше не оставляет роутер заблокированным.
- В новых настройках предпочтительны NFQWS2 и VLESS через Sing-box/Xray. WARP и другие VPN включаются отдельно; сохранённый выбор пользователя не меняется.
- Исправлено возобновление прерванного восстановления NFQWS2. Прежний профиль заново проверяется и запускается; отказ после запуска убирает только созданный процесс.
- Подбор VLESS продолжается после подтверждённого отказа конкретного узла и полного отката. Неопределённый результат восстановления по-прежнему останавливает изменения сети.
- Уточнены причины отказов NFQWS2, доступность кнопок обновления компонентов и инструкция удаления старой установки.

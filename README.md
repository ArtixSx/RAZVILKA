# RAZVILKA

Локальная панель для Keenetic и Netcraze с Entware: сервисы, подключения,
обходы и устройства в одном месте. Выберите нужные сайты и устройства,
проверьте подключение и примените маршрут вручную или разрешите Автопилоту
подбирать проверенный резерв. Программа и сохранённые расписания работают
на роутере, даже когда браузер закрыт. Облачный аккаунт RAZVILKA не нужен.

**RAZVILKA 0.18.4** — Автопилот, проверка подключений, настройка обходов
и локальные инструменты конфигурации. [Проверенные сценарии и ограничения](docs/CURRENT_STATUS_RU.md)
описаны отдельно. Команда установки ниже получает опубликованный стабильный выпуск.

## Возможности текущего проекта

- Сервисы и маршруты для выбранных устройств; проверка, применение и возврат
  к прежним настройкам при ошибке.
- Подключения VLESS, Hysteria2, TUIC и Shadowsocks: импорт, подписки,
  понятные названия стран, проверка узлов и разрешённый резерв.
- Настройки NFQWS2, Sing-box/Xray, USQUE, WARP и AmneziaWG — в пределах
  возможностей установленного компонента и профиля.
- Автопилот с мастером первоначальной настройки, областью устройств,
  разрешёнными источниками и расписанием проверок.
- Диагностика, версии компонентов, сравнение DNS-ответов и приватные
  резервные копии. Тёмная тема включена по умолчанию.

В версии 0.18.4 также есть **экспорт конфигурации Mihomo**, **экспериментальный
генератор профиля HEV** и **ручной импорт/экспорт пакетов стратегий NFQWS2**.
Mihomo и HEV пока не подключены как готовые управляемые обходы; создание файла
не запускает их на роутере. Импорт стратегии добавляет кандидата для отдельной
проверки. Автоматическая установка обновлений ещё не включена: расписание
может проверять версии и готовить архив приложения.
[Подробнее об EXT5 и оставшейся работе](docs/extensions/EXT5_RU.md).

## Чистая установка

Сначала установите Entware для своей модели и прошивки. Если флешка очищена,
сначала восстановите Entware и подключение `/opt`. Команды выполняются через
SSH от `root`:

```sh
test -d /opt && command -v opkg
opkg update
opkg install curl ca-certificates coreutils-sha256sum tar
```

Установите последний **стабильный** выпуск:

```sh
curl -fsSL https://raw.githubusercontent.com/ArtixSx/RAZVILKA/main/scripts/bootstrap.sh | sh
```

Установщик выбирает бинарник для архитектуры роутера, проверяет SHA256,
устанавливает панель и проверяет её запуск. Поддержаны варианты `arm64`
(aarch64), `mipsle` (mipsel), `mips` и `amd64`. Нужные компоненты обхода
устанавливаются отдельно; совместимость зависит также от модели и ядра.

## Первое использование версии 0.18.4

Ниже описан порядок настройки версии 0.18.4.

1. Откройте `http://192.168.1.1:8787` в локальной сети. Если у роутера другой
   LAN-адрес, используйте его. Задайте собственные логин и пароль.
2. В мастере выберите устройства, сервисы, доступные методы и источники.
   На чистой установке 0.18.4 базовый каталог содержит шесть групп NFQWS2;
   дополнительные сервисы добавляются отдельно.
3. Настройте нужный обход или импортируйте подключение, затем проверьте его
   для выбранного сервиса.
4. Примените изменения либо разрешите Автопилоту работать в выбранной области.
   Safe Mode включён по умолчанию и снимается отдельным действием.

Запущенный процесс, ответ DNS или открытый порт ещё не означают, что сайт
работает через нужный маршрут. Результат проверки смотрите у самого сервиса.

Версия и состояние установленной панели:

```sh
/opt/bin/razvilka -version
/opt/etc/init.d/S99razvilka status
/opt/etc/init.d/S99razvilka lan-ip
```

## Обновление и документация

Архивы опубликованных версий находятся в [Releases](https://github.com/ArtixSx/RAZVILKA/releases).
Для ручного обновления распакуйте Entware-архив выбранного выпуска и из его
каталога выполните предварительную проверку, затем установку:

```sh
sh scripts/upgrade-entware.sh --dry-run
sh scripts/upgrade-entware.sh --apply
```

Переходите к установке после успешной предварительной проверки. Сохраните
приватную резервную копию и напечатанный установщиком путь снимка для отката.
При обновлении существующий пользовательский каталог сохраняется.

Подтверждённые результаты и ограничения собраны в
[текущем статусе](docs/CURRENT_STATUS_RU.md), планы — в
[документации EXT5](docs/extensions/CODEX_EXT5_RU.md). История версий и прежних
испытаний находится в [Changelog](CHANGELOG.md) и [отчётах](docs/releases).
Испытания старой сборки не подтверждают новую; сборка под архитектуру
не заменяет проверку на конкретном роутере.

# RAZVILKA

Локальная панель для Keenetic/Netcraze с Entware. Выберите сервисы и устройства,
добавьте подходящие подключения и разрешите проверку маршрутов. Настройки,
проверки, применение, резервные копии и Автопилот выполняются на роутере.
Сохранённые расписания работают и при закрытом браузере.

Панель открывается по LAN-адресу роутера на порту **8787** — обычно
`http://192.168.1.1:8787`. Адрес вашей установки выводит штатный init-скрипт.
Учётная запись и приватные профили хранятся локально; облачный аккаунт
RAZVILKA не требуется.

## Что можно делать

- Управлять сервисами и областью устройств, просматривать план и применять
  маршрут с проверкой и откатом при ошибке.
- Использовать NFQWS2, Sing-box/Xray, USQUE, WARP и AmneziaWG в пределах
  возможностей установленного компонента и проверенного профиля.
- Импортировать подключения и HTTPS-подписки, проверять конкретный узел для
  сервиса, сохранять разрешённый резерв и расписание проверок.
- Передавать выбранные сервисы Автопилоту с явными разрешениями. Обновление
  подписки получает кандидатов; включение маршрутов требует отдельного допуска.
- Работать с собственным AWG-профилем, создавать и восстанавливать приватные
  копии, видеть состояние компонентов, маршрутов и ресурсов роутера.
- Сравнивать DNS-ответы A/AAAA для существующего сервиса через выбранные DoH-профили.

Точный сервисный тест пары **DNS + маршрут**, применение DNS только выбранным
сервисам/устройствам и автоматический подбор таких пар остаются этапами
**DC2–DC4**. Подписанные рекомендации пока представлены офлайн-библиотекой:
скачивание облачного каталога и отправка результатов не включены.
Доступность конкретного сервиса проверяется отдельно; запущенный процесс,
ответ DNS и открытый TCP-порт сами по себе её не подтверждают.

## Установка

Нужны установленный Entware, подключённый `/opt` и SSH-доступ `root`.
Первичная установка Entware зависит от модели и прошивки роутера.
Для неоднозначного `uname -m = mips` важно различать BE и LE: установщик
RAZVILKA проверяет ELF работающей оболочки и отказывает при неизвестном результате.

Подготовьте HTTPS-загрузчик и проверку целостности:

```sh
test -d /opt && command -v opkg
opkg update
opkg install curl ca-certificates coreutils-sha256sum tar
```

**Стабильный канал** — эта команда устанавливает `latest stable`, сейчас `v0.18.0`:

```sh
curl -fsSL https://raw.githubusercontent.com/ArtixSx/RAZVILKA/main/scripts/bootstrap.sh | sh
```

**Кандидат DC1** — следующая команда предназначена для использования **после
публикации тега и файлов `v0.18.2-rc.1`**. Версия задаётся процессу установщика:

```sh
curl -fsSL https://raw.githubusercontent.com/ArtixSx/RAZVILKA/v0.18.2-rc.1/scripts/bootstrap.sh | RAZVILKA_VERSION=v0.18.2-rc.1 sh
```

Можно скачать и распаковать Entware-архив выбранного выпуска. В его каталоге:

```sh
sh scripts/upgrade-entware.sh --dry-run
sh scripts/upgrade-entware.sh --apply
```

Выполняйте вторую команду только после успешной предварительной проверки.
Установщик сверяет SHA256, сохраняет снимок, устанавливает панель и проверяет
её запуск. Сохраните напечатанный путь снимка для штатного отката.
По умолчанию устанавливается панель; нужные обходы добавляются отдельно.
При первом входе задайте собственные логин и пароль. Safe Mode по умолчанию
включён; сетевые изменения требуют явного разрешения.

## Открыть и проверить панель

```sh
/opt/bin/razvilka -version
/opt/etc/init.d/S99razvilka status
LAN_IP=$(/opt/etc/init.d/S99razvilka lan-ip)
/opt/bin/razvilka -healthcheck "http://$LAN_IP:8787/api/v1/status"
```

Откройте `http://<LAN_IP>:8787` из локальной сети. Затем проверьте нужный сервис
и подключение в панели. Не публикуйте её порт в интернет.

## Ограничения и помощь

Аппаратная приёмка учитывается отдельно для каждого бинарника. Реальные
AWG 3.1/WARP, WAN reconnect, перезагрузка, IPv6 HTTPS, слабая память и
24–72 часа работы требуют своей проверки. Кросс-сборки ARM64, MIPS, MIPSle
и amd64 не подтверждают работу на всех устройствах. Публичные узлы могут
перестать работать после успешной проверки.

История опубликованных версий сохранена в [Changelog](CHANGELOG.md).
Старые отчёты A1/UI2/R3/DC1 описывают свои исходные срезы; текущий статус —
в [CURRENT_STATUS_RU.md](docs/CURRENT_STATUS_RU.md).

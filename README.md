# RAZVILKA

**Нужные сервисы через подходящее подключение — на вашем роутере.**

Локальная веб-панель для **Keenetic и Netcraze с Entware**. Выбирайте сайты и
устройства, проверяйте доступность, управляйте NFQWS2, WARP и VPN-подключениями
в одном месте. Панель и расписания работают на роутере, даже когда браузер закрыт.

[Скачать стабильную версию](https://github.com/ArtixSx/RAZVILKA/releases/latest) ·
[Установка](#установка) · [Документация](docs/README.md) · [English](README_EN.md) ·
[Новости и поддержка](https://t.me/RAZVILKA_UI)

## Что можно делать

| Раздел панели | Для чего он нужен |
| --- | --- |
| Главная и Автопилот | Смотреть состояние сети, выбрать сервисы, устройства и разрешённые варианты подключения |
| Сервисы | Назначать маршрут сайту или приложению, проверять доступ и применять изменения |
| Подключения | Добавлять VLESS и другие профили, обновлять подписки, выбирать узлы по стране и результатам проверки |
| Обходы | Устанавливать и настраивать нужные компоненты: NFQWS2, WARP, Sing-box и другие |
| Устройства | Ограничивать действие маршрута выбранными устройствами |
| События и настройки | Смотреть причины ошибок, версии компонентов и управлять резервными копиями |

Автопилот действует в заданных вами пределах. Доступность сайта зависит от
выбранного узла, провайдера и возможностей роутера; запущенный процесс сам по себе
не подтверждает рабочее подключение.
[Что проверено и какие ограничения остаются](docs/CURRENT_STATUS_RU.md).

## Установка

### 1. Подготовьте Entware

Нужны установленный **Entware**, подключённый `/opt` и доступ по SSH
к оболочке Entware от `root`. Если Entware ещё нет, начните с
[подготовки роутера](docs/INSTALL_RU.md#подготовка-entware).
Приглашение `(config)>` относится к консоли прошивки; команды ниже выполняются
в оболочке Entware.

| Платформа | Подходящий Entware | Бинарник RAZVILKA |
| --- | --- | --- |
| AArch64 / ARM64 | [aarch64-k3.10](https://bin.entware.net/aarch64-k3.10/installer/aarch64-installer.tar.gz) | `arm64` |
| MIPS | [mipssf-k3.4](https://bin.entware.net/mipssf-k3.4/installer/mips-installer.tar.gz) | `mips`, soft-float |
| MIPSel | [mipselsf-k3.4](https://bin.entware.net/mipselsf-k3.4/installer/mipsel-installer.tar.gz) | `mipsle`, soft-float |

Проверьте, что Entware доступен:

```sh
export PATH=/opt/sbin:/opt/bin:/opt/usr/sbin:/opt/usr/bin:$PATH
test -d /opt && command -v opkg
```

Если команда не вывела путь к `opkg`, завершите подготовку Entware.
Затем установите средства HTTPS-загрузки:

```sh
opkg update && opkg install curl wget-ssl ca-certificates ca-bundle
```

Если обновление каталога сообщает `wget: not an http or ftp url`, используйте
[короткую инструкцию восстановления HTTPS](docs/INSTALL_RU.md#если-каталоги-пакетов-не-обновляются).

### 2. Скачайте и запустите установщик

```sh
mkdir -p /opt/tmp &&
curl -fsSL --retry 2 -o /opt/tmp/razvilka-setup.sh \
  https://raw.githubusercontent.com/ArtixSx/RAZVILKA/main/scripts/bootstrap.sh &&
sh /opt/tmp/razvilka-setup.sh
```

Скрипт запустится только после успешной загрузки. Он добавит недостающие базовые
утилиты, выберет архитектуру, проверит контрольные суммы стабильного выпуска
и запустит панель. Нужные компоненты обхода устанавливаются отдельно.

### 3. Откройте панель и настройте подключение

Откройте **[http://192.168.1.1:8787](http://192.168.1.1:8787)** — либо адрес своего
роутера с портом `8787`. Точный адрес будет в выводе установщика.

1. Используйте выведенный ключ или ссылку первого входа, затем задайте логин и пароль.
   Сохраните ключ восстановления в надёжном месте.
2. В мастере «Автопилот» выберите сервисы и устройства или перейдите к ручной настройке.
3. Установите нужный компонент в разделе «Обходы»; добавьте VLESS или другой профиль
   в разделе «Подключения».
4. Проверьте доступ к выбранному сервису и примените маршрут. На новой установке
   безопасный режим включён; разрешение работы маршрутов задаётся отдельно.

## Обновление

Повторный запуск установщика получает последний стабильный выпуск, сохраняет
настройки и создаёт снимок для отката:

```sh
mkdir -p /opt/tmp &&
curl -fsSL --retry 2 -o /opt/tmp/razvilka-setup.sh \
  https://raw.githubusercontent.com/ArtixSx/RAZVILKA/main/scripts/bootstrap.sh &&
sh /opt/tmp/razvilka-setup.sh
```

Дождитесь результата проверки и сохраните напечатанный путь снимка.
Если маршрут не подтверждён после обновления, смотрите результат установки
и диагностику — наличие работающей панели не означает, что обход восстановлен.

Проверить версию и состояние панели:

```sh
/opt/bin/razvilka -version
/opt/etc/init.d/S99razvilka status
```

## Удаление

```sh
mkdir -p /opt/tmp &&
curl -fsSL --retry 2 -o /opt/tmp/razvilka-setup.sh \
  https://raw.githubusercontent.com/ArtixSx/RAZVILKA/main/scripts/bootstrap.sh &&
sh /opt/tmp/razvilka-setup.sh --uninstall
```

Удаляются панель, её автозапуск и собственные активные маршруты. Настройки,
подключения и резервные копии сохраняются для повторной установки.
Entware и отдельно установленные компоненты остаются на месте.

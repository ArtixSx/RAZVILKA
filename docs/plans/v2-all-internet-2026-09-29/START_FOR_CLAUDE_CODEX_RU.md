# Начать здесь — RAZVILKA V2, Claude Code / Codex

Прочитай MASTER_PLAN_V2_RU.md и GLOBAL_POLICY_SPEC_RU.md. Работай с actual checkout ArtixSx/RAZVILKA; сверенная база 46ba8761 (функциональный выпуск 0.18.15 / 450496ed). При более новом HEAD не откатывай изменения.

КРИТИЧЕСКОЕ УТОЧНЕНИЕ ВЛАДЕЛЬЦА:
Новая установка должна обслуживать ВЕСЬ ИНТЕРНЕТ устройств выбранных домашних сегментов, кроме исключённых устройств и сайтов. Выбранные сервисы — отдельные правила/проверки поверх общего подключения, НЕ allowlist всего обхода. Ноль выбранных сервисов допустим. Новый сайт вне каталога использует default. Сужение scope/удаление override возвращает default, а не BASE.

Порядок: минимальные safety fixes + существующий global policy contract → Xray → обычный WireGuard → AmneziaWG → единый Autopilot default/service → исполнение LAN/RU/DNS исключений → остальные направления. Не откладывай Xray ради ещё одной полной перестройки UI. Но не включай общий режим на рабочей сети до проверки исключений и recovery.

Сначала инструкции репозитория, git status/HEAD/worktrees/VERSION/go.mod и baseline штатных тестов. Кратко сопоставь фактическую реализацию с задачами и начни небольшой проверяемый PR. Не создавай новый Autopilot/очередь/NodeStore. Не накладывай старые ZIP. Не используй голый all_except флаг как доказательство runtime.

Уровни implementation/unit/integration/native/HIL/soak раздельны. В ACCEPTANCE_MATRIX.json все кейсы пока not_run. Нет HIL — продолжай код/тесты и отметь блокер; не публикуй ложную готовность. Сохрани улучшения 0.18.14–0.18.15; прежние audit findings сначала воспроизведи.

Не публиковать/force-push/менять рабочий роутер/удалять чужое ПО/создавать внешние аккаунты/VPS без отдельного разрешения. Нормальная автоматизация в готовом продукте действует по один раз сохранённой политике без повторных подтверждений.

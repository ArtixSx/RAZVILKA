## Первые действия

Сначала G00 и воспроизведение необходимых G01/G02. Затем G03 как небольшой контракт/test PR, сразу X01. X02 не закрывается без manual lifecycle и безопасного scoped default test. Подготовка WG после X02 не обязана ждать недоступного физического HIL X03. Аналогично AWG после W02. F01 проектирует общие targets; E/D завершает их широкий runtime и exclusions.

Общий режим становится default предлагаемого нового мастера, а не молча включённым global capture при установке бинарника. Исходная политика и промежуточные версии остаются безопасными до однократного согласия и технической готовности.

Завершение одного API/парсера/кнопки не закрывает engine lifecycle. Блокер HIL фиксируется отдельно; все релизные заявления привязаны к фактически проверенной комбинации hardware/runtime/protocol.

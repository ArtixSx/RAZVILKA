# План V2 «Весь интернет» — действующая точка правды

Принят 29 сентября 2026 года по заданию владельца. Заменяет очередь и продуктовые
значения по умолчанию [предыдущего плана](../unified-lan-2026-09-22/README.md):
основной режим — **весь интернет устройств выбранных домашних сегментов, кроме
исключённых устройств и сайтов**; выбранные сервисы — отдельные правила поверх
общего пути, а не список разрешённого для обхода.

Файлы пакета — исходные документы владельца; контрольные суммы в
[SHA256SUMS.txt](SHA256SUMS.txt) совпадают с полученным архивом.

- [MASTER_PLAN_V2_RU.md](MASTER_PLAN_V2_RU.md) — полный план;
- [GLOBAL_POLICY_SPEC_RU.md](GLOBAL_POLICY_SPEC_RU.md) — семантика общего режима;
- [WORK_ORDER_RU.md](WORK_ORDER_RU.md) и [TASKS.json](TASKS.json) — очередь задач;
- [ACCEPTANCE_MATRIX.json](ACCEPTANCE_MATRIX.json) — проверяемые сценарии
  (статусы в пакете — `not_run`; фактические результаты ведутся в журнале);
- [DECISIONS_CROSSWALK_RU.md](DECISIONS_CROSSWALK_RU.md) — что заменено и сохранено.

Фактическое выполнение, команды и уровни подтверждения —
в [журнале выполнения](EXECUTION_RU.md). История прежнего плана и его HIL-результаты
остаются в `docs/plans/unified-lan-2026-09-22/` и не переписываются.

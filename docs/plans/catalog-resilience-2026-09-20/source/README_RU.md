# Что в комплекте

Это диагностика и задание Codex, НЕ обновление RAZVILKA.
Проект, релизы и роутер не изменялись.

- CODEX_CATALOG_RESILIENCE_RU.md: причина отказа полного preview, архитектура
  резервных источников и 20 запланированных сценариев.
- Telegram_V2Fly_domains.txt: 21 домен без изменения состава, снятые с V2Fly
  20 сентября 2026. Git blob проверен. Включены связанные ресурсы экосистемы
  (в том числе fragment.com, ton.org); проверьте состав перед импортом.
- Telegram_official_CIDRs.txt: 14 сетей с официальной страницы Telegram,
  нормализованные окончания строк. Не содержит ключей и серверов VLESS.
- CIDR_COMPARISON.json: вычисленное сравнение официального состава и полученных
  Loyalsoldier/MetaCubeX. Это сравнение данных, не сетевой тест.
- SOURCE_MANIFEST.json / SHA256SUMS: происхождение и целостность этого комплекта;
  НЕ подпись издателя и НЕ разрешение для автоустановки.
- build_data.py: воспроизведение сравнения и проверки зафиксированных входных данных.

## Временный импорт без получения файлов роутером из интернета

В диалоге «Свой GitHub-файл, локальный файл или текст» можно выбрать
Telegram_V2Fly_domains.txt, тип «Домены», название «Telegram — доменная часть».
URL источника оставьте пустым, чтобы использовать ровно локальный файл.
Для веб-пробы подходит https://telegram.org/ — этот домен присутствует в файле.
Сначала разберите и проверьте preview. Не включайте автоматическое применение
на основании одного успешного импорта. Конфликты с уже существующим сервисом
следует разрешить до добавления, не создавать вслепую второй Telegram.

Такой вариант обходит загрузку core.telegram.org только для ДОМЕННОЙ части.
Он не эквивалентен исходной карточке «домены и сети», не гарантирует маршрутизацию
нативного приложения по прямым IP и не подтверждает медиа или звонки.
Сохранение определения не означает, что выбран обход или проверен сервис.

Отдельный Telegram_official_CIDRs.txt передан для восстановления полного
определения в Codex/редакторе. Не вставляйте его в поле «Домены». Не импортируйте
две половины как две независимые полные карточки и не подменяйте весь
configs/community-catalog.json этими файлами. Объединение доменов и сетей должно
иметь один осознанно показанный состав и проверку текущей конфигурации.

На роутере пользователя импорт и внешняя доступность этим комплектом не проверены.
Снимки могут устаревать; дата получения не является гарантией полноты всех функций.

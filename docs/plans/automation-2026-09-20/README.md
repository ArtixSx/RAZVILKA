# Продолжение автоматизации: план от 20 сентября 2026 года

Это полученное задание по развитию приложения, а не новый установочный пакет.
Исходный аудит относится к 0.18.5 и ревизии `d8355a9`. Продолжать нужно текущую
ветку проекта, сохраняя последующие исправления установки 0.18.6.

| Файл | Для чего нужен |
| --- | --- |
| [Подробный план](AUDIT_AND_IMPLEMENTATION_RU.md) | Десять находок, 15 этапов, ожидаемое поведение и места изменения кода |
| [Проверки для чтения](ACCEPTANCE_MATRIX_RU.md) | 104 сценария с условиями и ожидаемым результатом |
| [Проверки в JSON](ACCEPTANCE_MATRIX.json) | Та же исходная матрица для инструментов разработчика |
| [Границы исходного аудита](AUDIT_SCOPE_AND_SOURCES.json) | Ревизии, источники и перечень того, что автор проверял |

Все четыре файла сохранены без изменения содержания. **104 сценария запланированы;
они не являются 104 успешными тестами.** Последующие результаты записываются
отдельно с ревизией и видом проверки. Текущие приоритеты — в
[основном плане](../../ROADMAP.md), фактические испытания — в
[статусе проекта](../../CURRENT_STATUS_RU.md).

Сверка с 0.18.6 подтвердила открытые задачи подписок, резервов, зависимостей USQUE,
автоустановки, DNS по отдельным доменам, обучения NFQWS2 и нативных Mihomo/HEV.
Уточнение к прежним формулировкам: готовый NFQWS2 после успешной проверки уже
может применяться автоматически; новый подбор стратегии при отказе ещё нужен.
Проверенная установка Entware не заменяет автоматическую установку обходов.

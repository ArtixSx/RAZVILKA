# Изменение комплекта: DNS-priority, 22 сентября 2026

Добавлены договорённости по раннему D1, 24 planned-сценария и первичные источники.
Обновлены задания, master plan, таблица соответствия, статусы и индексы требований.

Все исходные файлы `patches/`, `overlay/`, `candidate/`, исполняемые скрипты и
прежние журналы `results/` сохранены побайтово. Это изменение документов, не
переработка DNS production-кода. Предыдущие результаты тестов — исторические
результаты исходного комплекта, в этой попытке они заново не выполнялись.

В этой попытке проверены CRC исходного/нового ZIP, исходный и новый SHA256-инвентарь,
JSON-структура/уникальность case ID, сохранность исполняемых входов и наличие всех
старых файлов. Live DNS, TLS, service, native-engine, роутерные и браузерные тесты
DNS не запускались. Никаких новых PASS для DNS не выставлено.

Хеши подтверждают целостность архива, а не подпись доверенного издателя.

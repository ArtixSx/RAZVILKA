# Что обнаружено при совместной перепроверке

Проверены реальные файлы двух предоставленных ZIP и повторены их исходные тесты. Успех этих тестов не доказывал совместимость с полным CI репозитория. Новые изменения сверены с production-исходниками через GitHub connector на c3722365.

| Новый panel-availability.js не имел version query | Версия 0.18.10 в теге ресурса, как у остальных | Сверка шаблона и integration test |

| Старый test-interface-home проверял прежнюю композицию | Заменён новым тестом текущих production-функций, с переносом значимых проверок: unknown/empty, zero metrics, freshness, applied/desired, auth | Не заменён пустым PASS; добавлены сценарии открытого инспектора |

## Не объявлено исправленным этим пакетом

Глобальная блокировка хранилищ на всё время части сетевых операций, полная durable-очередь, event-drain recovery, автоматическая установка/обновления, DNS per-domain ledger, A→B-apply-fail→C, адаптивное обучение NFQWS2 и native Mihomo/HEV остаются задачами backend. UI-pause не заменяет Stop, строка доступности панели не заменяет наблюдение клиентского пути.

Во время добавления semantic digest в кандидат Go промежуточная сборка обнаружила ошибочное включение блока в другой обработчик. Ошибка исправлена, два последующих race-прогона и vet прошли; промежуточный журнал сохранён в results/earlier-attempt. Это не скрытый успешный прогон.

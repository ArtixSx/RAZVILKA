# E1 — приёмка

Все 40 сценариев запланированы. Файловая проверка комплекта не выполняет эти сценарии.

## LE-001. lan_except не включает весь интернет

Условия: Сохранить lan_except с selected_services.

Ожидается: Неизвестные назначения остаются на исходном пути; только выбранные сервисы получают обход.

Уровни: real_http_integration, native_engine, router_client_hil. Статус: **planned**.

## LE-002. Новый клиент наследует домашний профиль

Условия: В принятом домашнем сегменте подключён новый не исключённый клиент.

Ожидается: Наследование без нового мастера; гостевой scope не расширяется.

Уровни: real_http_integration, native_engine, router_client_hil. Статус: **planned**.

## LE-003. Гостевой сегмент не наследуется

Условия: Добавить guest-сегмент после сохранения домашнего профиля.

Ожидается: Guest не включён до отдельного разрешения.

Уровни: real_http_integration, native_engine, router_client_hil. Статус: **planned**.

## LE-004. Трафик самого роутера отделён

Условия: Включить lan_except, вызвать служебную загрузку/регистрацию.

Ожидается: Выбранный ранее служебный путь не подменён клиентским catch-all.

Уровни: real_http_integration, native_engine, router_client_hil. Статус: **planned**.

## LE-005. Исключение одного устройства

Условия: Два клиента, один исключить во время работы.

Ожидается: Новые потоки исключённого клиента не используют owned NFQ/proxy/Smart DNS; второй сохраняет работу.

Уровни: real_http_integration, native_engine, router_client_hil. Статус: **planned**.

## LE-006. Смена DHCP-адреса

Условия: Исключённый клиент получил новый IPv4.

Ожидается: Исключение следует за подтверждённой identity, не только за старым IP.

Уровни: real_http_integration, native_engine, router_client_hil. Статус: **planned**.

## LE-007. Повторная выдача IPv4

Условия: Старый IPv4 исключённого клиента получил другой клиент.

Ожидается: Устаревшая адресная запись не переносит исключение на другого клиента.

Уровни: real_http_integration, native_engine, router_client_hil. Статус: **planned**.

## LE-008. IPv6 и prefix renewal

Условия: Исключённый клиент использует новые IPv6 адреса после смены префикса.

Ожидается: Поддержанное сопоставление исключает его IPv6; неподдержанное не выдаёт полную гарантию.

Уровни: real_http_integration, native_engine, router_client_hil. Статус: **planned**.

## LE-009. Изменение private MAC

Условия: Клиент подключился с неизвестным новым MAC.

Ожидается: Не выдумывать прежнюю identity по имени; объяснить режим наследования и ограничения.

Уровни: real_http_integration, native_engine, router_client_hil. Статус: **planned**.

## LE-010. Устройство временно не наблюдается

Условия: Известное исключённое устройство уснуло/исчезло из текущего списка.

Ожидается: Запись исключения сохраняется; не расширять scope и не стирать ручное правило.

Уровни: unit, real_http_integration. Статус: **planned**.

## LE-011. Пропавшая native policy

Условия: Политика, использованная исполнителем, удалена/переименована.

Ожидается: Нет перехода к all LAN; новый план затронутой области отклонён, панель доступна.

Уровни: real_http_integration, native_engine, router_client_hil. Статус: **planned**.

## LE-012. Неопределённая идентичность сегмента

Условия: Меняется интерфейс/bridge, совпадает старое имя.

Ожидается: Требуется подтверждённая identity, не wildcard всех приватных сетей.

Уровни: real_http_integration, native_engine, router_client_hil. Статус: **planned**.

## LE-013. Глобальное исключение сильнее назначения сервиса

Условия: Для исключённого устройства сервис имеет явный proxy pin.

Ожидается: Сервис не включает обработку исключённого устройства.

Уровни: unit, real_http_integration. Статус: **planned**.

## LE-014. Индивидуальный scope только сужает

Условия: Глобально разрешён home; сервис содержит иной CIDR.

Ожидается: Пересечение, а не объединение; чужой сегмент не включается.

Уровни: unit, real_http_integration. Статус: **planned**.

## LE-015. Старые selected-настройки после миграции

Условия: Обновить установку с двумя выбранными адресами.

Ожидается: Не переключать на lan_except, не включать RU-каталог скрыто.

Уровни: unit, real_http_integration. Статус: **planned**.

## LE-016. Ручной direct против автоматического подбора

Условия: Общий автопилот пытается подобрать путь для ручного исключения.

Ожидается: Ручное без обхода сохраняется; не выполнять proxy probes без разрешения.

Уровни: real_http_integration, native_engine, router_client_hil. Статус: **planned**.

## LE-017. Обход поверх авто-RU

Условия: Российский сервис явно получил bypass override.

Ожидается: Auto-RU не отменяет override и последующие обновления его не стирают.

Уровни: real_http_integration, native_engine, router_client_hil. Статус: **planned**.

## LE-018. Два противоположных обязательных правила

Условия: Одна область содержит mandatory direct и mandatory tunnel.

Ожидается: Новый конфликтующий план не применяется; явное объяснение без случайного приоритета.

Уровни: unit, real_http_integration. Статус: **planned**.

## LE-019. Не-.ru домен российского сервиса

Условия: Curated vendor snapshot содержит сервис с доменом .com.

Ожидается: Он учитывается по составу списка, не только по TLD.

Уровни: unit, real_http_integration. Статус: **planned**.

## LE-020. Неявный broad TLD из category-ru

Условия: Curated importer встречает include:tld-ru.

Ожидается: Не маскировать его под per-service список; отклонить/разделить широкую область.

Уровни: unit, real_http_integration. Статус: **planned**.

## LE-021. Optional зоны выключены

Условия: Посторонний *.ru домен не входит в curated профиль.

Ожидается: Он не получает auto-RU только из имени зоны; следует обычной политике.

Уровни: unit, real_http_integration. Статус: **planned**.

## LE-022. Optional зоны включены явно

Условия: Пользователь выбрал ровно ru/рф/su.

Ожидается: Правильное suffix/IDNA сопоставление; остальные TLD из upstream не добавляются.

Уровни: unit, real_http_integration. Статус: **planned**.

## LE-023. Граница имени, IDNA и URL-path

Условия: Ввести mixed case, trailing dot, IDN, example.ru.attacker.test и HTTPS URL с путём.

Ожидается: Нормализация без расширения на похожий домен; объясняется доменная, не URL-path область.

Уровни: unit, real_http_integration. Статус: **planned**.

## LE-024. Точное правило не становится suffix

Условия: Импортировать full:host.example и domain:zone.example.

Ожидается: Различие сохраняется до исполнителя либо сообщается неподдержанный тип.

Уровни: real_http_integration, native_engine, router_client_hil. Статус: **planned**.

## LE-025. Российский IP не означает российский сервис

Условия: Иностранный сервис имеет адрес, классифицированный как RU.

Ожидается: Без opt-in GeoIP нет автоматического direct-исключения.

Уровни: unit, real_http_integration. Статус: **planned**.

## LE-026. Общий CDN-адрес

Условия: RU/direct и explicit proxy имена делят один IP одного клиента.

Ожидается: Domain-aware исполнение или точный конфликт; никакого общего direct IP-set.

Уровни: real_http_integration, native_engine, router_client_hil. Статус: **planned**.

## LE-027. Имя назначения недоступно

Условия: Поток по IP literal/private DNS/закрытому имени.

Ожидается: Не выдавать догадку за совпадение списка; следовать согласованному unknown-mode.

Уровни: real_http_integration, native_engine, router_client_hil. Статус: **planned**.

## LE-028. Разные DNS views двух клиентов

Условия: Один телефон использует Smart DNS, ноутбук исключён.

Ожидается: Ответ gateway не попадает из общего кэша к исключённому клиенту.

Уровни: real_http_integration, native_engine, router_client_hil. Статус: **planned**.

## LE-029. Отсутствует per-client DNS capability

Условия: Исполнитель видит только запросы общего stub.

Ожидается: Не обещать device-scoped Smart DNS; отказ именно комбинации без глобального сбоя.

Уровни: real_http_integration, native_engine, router_client_hil. Статус: **planned**.

## LE-030. Ручное исключение при аварии direct

Условия: Базовый путь недоступен для исключённого сайта.

Ожидается: Показать недоступность; без скрытого fallback на proxy.

Уровни: real_http_integration, native_engine, router_client_hil. Статус: **planned**.

## LE-031. Источник недоступен при старте

Условия: После reboot GitHub не отвечает.

Ожидается: Загружается принятый persistent snapshot с возрастом, не пустой список.

Уровни: real_http_integration, native_engine, router_client_hil. Статус: **planned**.

## LE-032. Пустая выдача/ошибка JSON

Условия: Обновление вернуло пустые, чрезмерные или повреждённые данные.

Ожидается: Кандидат отвергнут; прежние effective исключения сохранены.

Уровни: unit, real_http_integration. Статус: **planned**.

## LE-033. Вредоносное расширение списков

Условия: В каталоге появляются /0, broad CDN или неожиданный TLD.

Ожидается: Не авторизуется обычным узким catalog update; проверка/отказ кандидата.

Уровни: unit, real_http_integration. Статус: **planned**.

## LE-034. Автоматическое штатное обновление

Условия: При разрешённом RU-каталоге появился небольшой допустимый набор записей.

Ожидается: Стадия проверки/применения без отдельных подтверждений каждой строки; manual override сохраняется.

Уровни: real_http_integration, native_engine, router_client_hil. Статус: **planned**.

## LE-035. 304 и версия принятого снимка

Условия: Источник возвращает Not Modified; локальный snapshot повреждён.

Ожидается: 304 не признаётся наличием данных; bounded refetch, без уничтожения действующего материала.

Уровни: unit, real_http_integration. Статус: **planned**.

## LE-036. Потерян ответ сохранения

Условия: Двойной клик/повтор запроса после таймаута.

Ожидается: Одно задание по identity; не повторять сеть вслепую, подтвердить фактический результат.

Уровни: unit, real_http_integration. Статус: **planned**.

## LE-037. Авария в применении исключений

Условия: Остановить процесс между DNS/rules/commit на изолированном стенде.

Ожидается: Startup сверяет журнал и owned ресурсы, восстанавливает согласованную версию.

Уровни: real_http_integration, native_engine, router_client_hil. Статус: **planned**.

## LE-038. Старые соединения после исключения

Условия: Активная долгая передача уже идёт через proxy, меняется исключение.

Ожидается: Статус convergence до завершения scoped миграции; не заявлять мгновенный direct.

Уровни: real_http_integration, native_engine, router_client_hil. Статус: **planned**.

## LE-039. Чужой VPN/фильтр и панель

Условия: Есть собственная политика Keenetic/AdGuard и VPN на клиенте.

Ожидается: Не удалять чужие настройки; UI не обещает global direct; доступность панели сохраняется.

Уровни: real_http_integration, native_engine, router_client_hil. Статус: **planned**.

## LE-040. Длительная работа all-except с резервом

Условия: Закрытый браузер; A отказал, B не применился, C работает, позже D; два сегмента и исключённый клиент.

Ожидается: Прежний A/B/C/D тест сохраняется; исключения и DNS views переживают failover/обновление; bounded ресурсы в 24/72h.

Уровни: real_http_integration, native_engine, router_client_hil, soak_24_72h. Статус: **planned**.

# Дополнительная приёмка внешних идей

**Все 48 случаев — planned. Это требования к будущим испытаниям, не результаты запуска.**

Точные связи с источниками, предлагаемыми изменениями и уровнями проверки — в `TRANSPORT_ACCEPTANCE.json` и `TRANSPORT_IDEAS.json`. Старые 24 DNSP и остальные матрицы не отменены; пересечения не складываются в число пройденных тестов.

## EXP-001. Повторный экспорт

**Условия:** Есть пригодная WG-регистрация; дважды экспортировать разные поддержанные форматы.

**Ожидаемый результат:** Ключ/account ID не меняются, счётчик внешних регистраций ноль; форматы валидны.

**Уровни:** unit, integration. **Статус:** planned. **Предложение:** R03.

## EXP-002. Изменение DNS/MTU

**Условия:** Менять только разрешённые локальные параметры сохранённого профиля.

**Ожидаемый результат:** Новый ExecutionSpec, но не новый KeyRef/AccountRef; старый active snapshot доступен для возврата.

**Уровни:** unit, integration. **Статус:** planned. **Предложение:** R03.

## EXP-003. Утрачен или повреждён private material

**Условия:** Сохранена запись аккаунта без пригодного ключа.

**Ожидаемый результат:** Не считать профиль проверенным; не создавать новый аккаунт скрыто; допустимые пути восстановления описаны.

**Уровни:** unit, integration. **Статус:** planned. **Предложение:** R03.

## EXP-004. Потерян register response

**Условия:** Тестовый API создал устройство и оборвал ответ.

**Ожидаемый результат:** Job enrollment-uncertain, повтор клика не создаёт второе устройство; readback используется только если поддержан.

**Уровни:** unit, integration. **Статус:** planned. **Предложение:** R04.

## EXP-005. 429 и reboot

**Условия:** Тестовый API возвращает Retry-After, затем процесс перезапускается.

**Ожидаемый результат:** Пауза и счётчик попыток сохранены; HTTP polling не обнуляет ограничения.

**Уровни:** unit, integration. **Статус:** planned. **Предложение:** R04.

## EXP-006. Смешанные пулы

**Условия:** В реестре WG, consumer H3 и Zero Trust H2 адреса.

**Ожидаемый результат:** Несовместимые кандидаты не пробуются как эквивалентные; результат хранит product/transport identity.

**Уровни:** unit, integration. **Статус:** planned. **Предложение:** R05.

## EXP-007. Малый ping, непригодный сервис

**Условия:** Кандидат A быстрее TCP, но целевой сервис отклоняет выход; B проходит.

**Ожидаемый результат:** A не выбирается по ping/стране, B допускается только со свежим результатом.

**Уровни:** integration, native. **Статус:** planned. **Предложение:** R05.

## EXP-008. Неисправен bootstrap

**Условия:** Действующий tunnel отказал, загрузчик endpoint по ошибке направлен через него.

**Ожидаемый результат:** Петля распознана; разрешённый служебный путь отдельный; пользовательский restricted трафик не выпускается direct.

**Уровни:** integration, native, hardware. **Статус:** planned. **Предложение:** R05.

## EXP-009. H3 отказал, H2 проходит

**Условия:** На собственном стенде UDP пути недоступен, проверенный H2 путь передаёт данные.

**Ожидаемый результат:** H2 может примениться после scoped probe, identity/readback и общей транзакции без отключения TLS.

**Уровни:** integration, native, hardware. **Статус:** planned. **Предложение:** R06.

## EXP-010. TCP открыт, туннеля нет

**Условия:** На H2 endpoint открыт TCP/443, но протокольная авторизация не проходит.

**Ожидаемый результат:** Нет PASS; не выводить успешный туннель из port-open.

**Уровни:** integration, native. **Статус:** planned. **Предложение:** R06.

## EXP-011. H2 неправильный pin

**Условия:** Правильный endpoint, несовпадающая серверная identity.

**Ожидаемый результат:** Кандидат отклонён, insecure не включается, прежний профиль сохранён.

**Уровни:** integration, native. **Статус:** planned. **Предложение:** R06.

## EXP-012. Неизвестный H2 IPv6

**Условия:** Реестр не содержит проверенного endpoint_h2_v6.

**Ожидаемый результат:** IPv6 не выдуман; применён только разрешённый поддержанный вариант либо показано ограничение.

**Уровни:** unit, integration. **Статус:** planned. **Предложение:** R06.

## EXP-013. Переключение режима требует enrollment

**Условия:** Тестовый API требует обновить режим и выделенные адреса.

**Ожидаемый результат:** До запроса снимок/receipt, readback обновляет точные поля, неудача не затирает единственный рабочий материал.

**Уровни:** integration, native. **Статус:** planned. **Предложение:** R04.

## EXP-014. Native TUN вместо sidecar

**Условия:** Один аккаунт и сервис сравниваются в обоих реальных режимах.

**Ожидаемый результат:** Координатор владеет routes/DNS; TCP/UDP проверяются; снижение ресурсов не заявляется без замеров.

**Уровни:** integration, native, hardware. **Статус:** planned. **Предложение:** R07.

## EXP-015. L4 для UDP сервиса

**Условия:** Выбрать TCP-only L4 для сценария, требующего UDP.

**Ожидаемый результат:** Capability mismatch до применения, без ложного успеха по веб-пробе.

**Уровни:** unit, integration. **Статус:** planned. **Предложение:** R07.

## EXP-016. Архитектура и listener

**Условия:** Загрузить совместимый бинарник на целевую архитектуру, проверить явный bind.

**Ожидаемый результат:** Нет неподтверждённого статуса для MIPS; внутренний SOCKS не открыт на всех интерфейсах.

**Уровни:** integration, native, hardware. **Статус:** planned. **Предложение:** R07.

## EXP-017. Повторные события и старый disconnect

**Условия:** После нового connect приходит событие от прежнего запуска.

**Ожидаемый результат:** События привязаны к generation, старое не снимает новый маршрут; очередь ограничена.

**Уровни:** unit, integration. **Статус:** planned. **Предложение:** R08.

## EXP-018. Crash без disconnect hook

**Условия:** Остановить собственный процесс до события; тестовый helper зависает.

**Ожидаемый результат:** Супервизор очищает owned ресурсы; helper ограничен, нет утечки процессов и бесконечного ожидания.

**Уровни:** integration, native, hardware. **Статус:** planned. **Предложение:** R08.

## EXP-019. Отсутствует именованная политика

**Условия:** До применения удалить тестовую политику устройств.

**Ожидаемый результат:** Нет расширения на весь LAN; блокируется только изменение с конкретной причиной.

**Уровни:** integration, native, hardware. **Статус:** planned. **Предложение:** R01.

## EXP-020. Изменена область во время применения

**Условия:** Область или системный policy ID меняются между preview и commit.

**Ожидаемый результат:** CAS/guard запрещает прежнее применение; excluded клиент не начинает обход.

**Уровни:** integration, native, hardware. **Статус:** planned. **Предложение:** R01.

## EXP-021. Скрытые обратные пакеты

**Условия:** На поддержанном тестовом PPE-устройстве наблюдать исходный/повторный/ответный поток.

**Ожидаемый результат:** Зафиксировано, что видит NFQWS2; до доказательства нет утверждения, что причина именно offload.

**Уровни:** integration, native, hardware. **Статус:** planned. **Предложение:** R02.

## EXP-022. Узкое исключение ускорения

**Условия:** Применить разрешённый per-flow эксперимент только к тестовому сервису/устройству.

**Ожидаемый результат:** Видимость и результат измерены; unrelated ускорение и throughput не выключены глобально.

**Уровни:** integration, native, hardware. **Статус:** planned. **Предложение:** R02.

## EXP-023. Нет PPE/connskip

**Условия:** Та же задача на платформе без целевых capabilities.

**Ожидаемый результат:** Неприменимая команда не выполняется; обычный runtime и панель доступны.

**Уровни:** integration, native. **Статус:** planned. **Предложение:** R02.

## EXP-024. Прошивка перезаписала таблицы

**Условия:** На тестовом роутере вызвать штатное WAN/netfilter событие.

**Ожидаемый результат:** Идемпотентно восстановлены только собственные правила без дубликатов и удаления чужих.

**Уровни:** integration, native, hardware. **Статус:** planned. **Предложение:** R02.

## EXP-025. Исторический рецепт

**Условия:** Передать строку с отсутствующим CLI/Lua feature в candidate registry.

**Ожидаемый результат:** Отказ в совместимости до запуска; не заменять неизвестный параметр похожим.

**Уровни:** unit, integration. **Статус:** planned. **Предложение:** R13.

## EXP-026. Семантический порядок

**Условия:** Рецепты с одинаковыми параметрами, но другим порядком стадий.

**Ожидаемый результат:** Не схлопываются в один hash, сохраняют порядок; user/vendor слои не перезаписываются.

**Уровни:** unit, integration. **Статус:** planned. **Предложение:** R13.

## EXP-027. TLS/браузер/QUIC

**Условия:** Контрольный TLS1.2 pass, другой клиент/TLS1.3/QUIC и связанные домены ещё не проверены.

**Ожидаемый результат:** PASS ограничен фактическим сценарием; web/video/voice не объединены.

**Уровни:** integration, native, hardware. **Статус:** planned. **Предложение:** R14.

## EXP-028. Широкая CDN и общий домен

**Условия:** Два сервиса используют часть общей зоны, третий независим.

**Ожидаемый результат:** Добавление/удаление не перехватывает всю CDN и не ломает references другого сервиса.

**Уровни:** integration, native, hardware. **Статус:** planned. **Предложение:** R14.

## EXP-029. Короткий ответ проходит, большой поток зависает

**Условия:** Собственный стенд с ограниченным MTU и контролируемыми потоками.

**Ожидаемый результат:** Раздельно диагностированы размер внешнего пути/внутренний MTU; аккаунт не пересоздан.

**Уровни:** integration, native, hardware. **Статус:** planned. **Предложение:** R09.

## EXP-030. Заблокирован ICMP

**Условия:** Контролируемый PMTUD-сценарий без ICMP ответов.

**Ожидаемый результат:** Нет ложного однозначного диагноза; ограниченная альтернативная проверка и безопасный прежний путь.

**Уровни:** integration, native. **Статус:** planned. **Предложение:** R09.

## EXP-031. Размеры IPv4/IPv6

**Условия:** Повторить профиль с обеими внешними семьями адресов.

**Ожидаемый результат:** Не копируется внутренний MTU из требования к внешнему пакету; проверено заданное покрытие.

**Уровни:** integration, native, hardware. **Статус:** planned. **Предложение:** R09.

## EXP-032. NAT и простой

**Условия:** Собственный NAT стенд, без и с согласованным keepalive.

**Ожидаемый результат:** Измерено восстановление после простоя; значение не изменяет остальные интерфейсы или ключи.

**Уровни:** integration, native, hardware. **Статус:** planned. **Предложение:** R10.

## EXP-033. Старое ядро и отсутствие GSO

**Условия:** Запуск на legacy ядре/стенде с отсутствующей оптимизацией.

**Ожидаемый результат:** Корректный fallback; способность core не выдумана по документации latest.

**Уровни:** integration, native, hardware. **Статус:** planned. **Предложение:** R17.

## EXP-034. Перегрузка буферов/CPU

**Условия:** Нагрузить тестовый путь в заранее согласованном лимите.

**Ожидаемый результат:** Drops/CPU/RSS наблюдаемы; исследование уступает управлению панелью, глобальные sysctl не переписаны.

## EXP-035. Проверенный TCP серверный профиль

**Условия:** Свой сервер, точные версии клиента/сервера, корректный REALITY target и параметры.

**Ожидаемый результат:** Полный service test и fallback-policy, нет открытого admin/controller endpoint.

**Уровни:** integration, native. **Статус:** planned. **Предложение:** R15.

## EXP-036. XHTTP и HTTP-посредник

**Условия:** Собственный разрешённый reverse proxy/CDN, разные поддержанные HTTP участки.

**Ожидаемый результат:** Проверяются mode/лимиты/реальный путь; HTTP200 промежуточной страницы не признаётся сервисом.

**Уровни:** integration, native. **Статус:** planned. **Предложение:** R15.

## EXP-037. TCP BBR/CUBIC A/B

**Условия:** Один контролируемый сервер и TCP маршрут, алгоритмы действительно доступны.

**Ожидаемый результат:** Сравнение под нагрузкой и возврат параметров, без утверждения об изменении QUIC.

**Уровни:** integration, native. **Статус:** planned. **Предложение:** R16.

## EXP-038. Brutal bandwidth завышен

**Ожидаемый результат:** Обнаружена деградация, недопустимый профиль не выбран по редкому пиковому прогону.

## EXP-039. WARP на VPS и управление

**Ожидаемый результат:** Сохранены SSH/admin/служебные маршруты; DNS actor и проверенный выход записаны.

## EXP-040. Один сервер с разными именами

**Ожидаемый результат:** Разные имена не считаются независимым резервом; метод независимости отражён явно.

## EXP-041. WARP-compatible AWG subset

**Ожидаемый результат:** Требуется native/wire проверка; до неё статус candidate, не весь AWG3.1 совместим.

## EXP-042. Peer-required AWG поле

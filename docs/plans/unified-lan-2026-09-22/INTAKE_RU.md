## Перенос и найденные проблемы

Автопилот стал первым блоком главной; основная навигация содержит шесть разделов.
Способы обхода доступны из настроек, прежние адреса технических страниц сохранены.
Проверка сервиса остаётся в карточке. Неприменённые изменения видимы, включая
ожидание выключения действующего маршрута.

Разделы загружаются независимо после проверки входа. Ошибка одного виджета
не удерживает навигацию. Новый запрос доступности панели читает только состояние
допуска операций из памяти; он не подтверждает работоспособность обхода.

Найдено и исправлено при переносе:

1. `apply_unified.py` использовал отсутствующий в Windows `os.fchmod`, включая
   возврат записи. Первый запуск остановился до замены исходника, дерево осталось
   чистым. Применена локальная обёртка: временный файл, закрытие, `os.chmod`,
   атомарный `os.replace`. Проверки базы/хешей/якорей сохранены; архив не изменён.
2. Общая защита API допускает часть диагностических чтений до настройки аккаунта.
   Новый endpoint дополнительно требует авторизацию и в этом состоянии.
   HTTP-тест покрывает анонимные GET/HEAD, busy/fenced, запрет мутации и сохранение
   блокировки после Stop/cancel.
3. Прежние тестовые окружения не учитывали независимую загрузку разделов и
   `closest`. Они адаптированы; проверки выхода, поздних ответов и отмены сохранены.
4. Проверка экрана входа привязана к фактическому `showAuth`, сохраняя требование
   показать публичный статус до перехода к форме входа.
5. В настоящем браузере фоновое обновление заменяло кнопку карточки, и после
   закрытия подробностей клавиатурный фокус терялся. Возврат теперь находит новую
   кнопку того же сервиса; выход из аккаунта и переход в другой раздел не перехватываются.

## Граница работы

Программные и выборочные браузерные проверки U0 пройдены; приёмка на роутере
остаётся открытой. Перенос не реализует LAN-исключения, Smart DNS executor,
постоянный каталог, durable-очередь, автоматический откат B с переходом к C или
установку обновлений по расписанию. Они переведены в единый план.
Сеть пользователя и версия на роутере этим переносом не меняются.
Аппаратные испытания и длительное наблюдение новой реализации пока не проведены.

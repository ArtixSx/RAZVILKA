# Что означают файлы и папки проекта

Чтобы установить RAZVILKA, не нужно разбираться во всех исходниках.
Начните с [главной страницы](../README.md) и
[инструкции установки](INSTALL_RU.md). Готовая программа находится в
[Releases](https://github.com/ArtixSx/RAZVILKA/releases/latest).

## Почему рядом с файлом на GitHub написан странный текст

В списке файлов справа GitHub показывает **сообщение последнего коммита**,
который затронул этот файл или папку. Это краткое описание изменения от автора,
а не название функции, инструкция или текущая версия программы. Дата справа —
дата этого изменения. Старое сообщение может оставаться у файла, который давно
не требовал правок.

## Какой файл скачивать из Releases

| Файл выпуска | Для чего |
| --- | --- |
| `RAZVILKA-<версия>-entware.tar.gz` | Полный комплект для установки на Entware |
| `RAZVILKA-<версия>-entware.zip` | Тот же комплект в ZIP для просмотра и ручной распаковки |
| `RAZVILKA-entware.tar.gz` | Копия комплекта с постоянным именем, которую получает bootstrap |
| `razvilka-linux-arm64`, `-mips`, `-mipsle`, `-amd64` | Отдельные бинарники; обычный установщик сам выбирает нужный из полного комплекта |
| `SHA256SUMS`, `*.SHA256SUMS`, `*.sha256` | Контрольные суммы для проверки загруженных файлов |
| GitHub «Source code (zip/tar.gz)» | Снимок исходников, а не готовый Entware-комплект |

## Где лежат настройки на роутере

При стандартной установке `/opt/bin/razvilka` — сама программа,
`/opt/etc/init.d/S99razvilka` — её запуск, `/opt/etc/razvilka` — настройки
и сохранённые подключения, `/opt/var/lib/razvilka` — рабочее состояние и копии,
`/opt/var/cache/razvilka` — кэш. Это пользовательские данные, они не относятся
к публичным исходникам. Не загружайте эти каталоги целиком в GitHub.

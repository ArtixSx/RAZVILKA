# RAZVILKA

> Черновик главной страницы для будущей 0.20.0, 09.10.2026. Выпуск ещё не принят.
> Установочные команды получают опубликованный стабильный выпуск; этот файл не подтверждает доступность 0.20.0.

**Нужные сервисы через выбранное подключение — на вашем роутере.**

Локальная веб-панель для **Keenetic и Netcraze с Entware**. Управляйте списком
сервисов, подключениями VLESS/VPN и NFQWS2, проверками доступа, компонентами
и резервными копиями. Панель и сохранённые расписания работают на роутере.

## Как выбирается трафик

Для 0.20.0 принят **обход только по активному списку**:

- Обход применяется к совпавшим сервисам, доменам и поддержанным IP/CIDR-правилам
  в выбранных домашних сетях. Список может действовать на всю выбранную сеть
  без назначения каждого сервиса каждому устройству.
- Устройство вне выбранной области или в исключениях использует обычную политику
  роутера. Ручные исключения ресурсов и действующий разрешённый российский список
  также имеют приоритет над положительными правилами и ручным закреплением обхода.
- Несовпавший трафик использует обычную политику роутера. Пустой активный список
  не включает обход.
- Одно подключение может обслуживать несколько записей списка. Выбор всей
  домашней сети как области устройств не превращает его в VPN для всего интернета.

[Полный контракт списков и исключений](../LIST_MODE_CORRECTION_RU.md).
Запущенный процесс или принятый запрос не подтверждает доступ к сервису;
результат применения и проверка доступа показываются отдельно.

## Установка

Подготовьте **Entware для своей модели**, смонтированный `/opt` и SSH-доступ
от `root` к оболочке Entware. Команды ниже не выполняются в консоли прошивки
с приглашением `(config)>`. [Подготовка Entware](../../../docs/INSTALL_RU.md#подготовка-entware).

Подготовьте HTTPS-загрузку:

```sh
export PATH=/opt/sbin:/opt/bin:/opt/usr/sbin:/opt/usr/bin:$PATH
opkg update && opkg install curl wget-ssl ca-certificates ca-bundle
```

Скачайте установщик и запустите его после успешной загрузки:

```sh
mkdir -p /opt/tmp &&
curl -fsSL --retry 2 -o /opt/tmp/razvilka-setup.sh \
  https://raw.githubusercontent.com/ArtixSx/RAZVILKA/main/scripts/bootstrap.sh &&
sh /opt/tmp/razvilka-setup.sh
```

Установщик выбирает архитектуру и проверяет SHA256 архива выпуска. Компоненты
обхода устанавливаются отдельно; установка панели сама по себе не включает маршруты.

Откройте `http://<LAN-адрес-роутера>:8787`, например
[http://192.168.1.1:8787](http://192.168.1.1:8787). Установщик печатает точный адрес.
По ключу или ссылке первого входа создайте логин и пароль, сохраните ключ
восстановления. Затем выберите сервисы и область устройств, добавьте подключение
или установите нужный компонент, проверьте доступ и примените план.
На новой установке Safe Mode включён; разрешение изменения рабочих маршрутов
задаётся отдельно в настройках.

## Обновление

Повторите скачивание и запуск установщика:

```sh
mkdir -p /opt/tmp &&
curl -fsSL --retry 2 -o /opt/tmp/razvilka-setup.sh \
  https://raw.githubusercontent.com/ArtixSx/RAZVILKA/main/scripts/bootstrap.sh &&
sh /opt/tmp/razvilka-setup.sh
```

Обычный путь обновления предусматривает сохранение настроек и снимок для отката.
Дождитесь результата, сохраните напечатанный путь снимка и проверьте состояние
маршрутов. Наличие работающей панели не подтверждает восстановление обхода.
Переход с 0.19.3 на будущую 0.20.0 ещё требует отдельной приёмки — см. ниже.
[Подробности обновления и отката](../../../docs/INSTALL_RU.md#обновление).

## Удаление

```sh
mkdir -p /opt/tmp &&
curl -fsSL --retry 2 -o /opt/tmp/razvilka-setup.sh \
  https://raw.githubusercontent.com/ArtixSx/RAZVILKA/main/scripts/bootstrap.sh &&
sh /opt/tmp/razvilka-setup.sh --uninstall
```

При успешном удалении скрипт останавливает панель, убирает её собственные маршруты,
бинарник и автозапуск. Настройки, подключения и снимки сохраняются; Entware
и отдельно установленные компоненты остаются. Ошибка остановки или очистки
останавливает удаление и сохраняет файлы панели.
[Удаление и откат](../../../docs/INSTALL_RU.md#удаление-и-откат).

## Короткая диагностика

```sh
/opt/bin/razvilka -version
/opt/etc/init.d/S99razvilka status
```

При ошибке разрешения имени проверьте DNS-настройки роутера и сообщение из панели
или установщика. При ошибках HTTPS-загрузки проверьте часы и сертификаты.
[Если панель не открывается](../../../docs/INSTALL_RU.md#если-панель-не-открывается) ·

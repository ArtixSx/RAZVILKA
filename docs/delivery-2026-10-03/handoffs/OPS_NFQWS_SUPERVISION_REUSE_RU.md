# OPS → NFQWS/CORE: reusable supervision boundary, 04.10.2026

Выбран вариант A: NFQWS-owned `internal/components/nfqws_supervision*.go` и собственные tests. Existing OPS package helpers не менять, fake opkg transaction и второй общий ledger не создавать. Файлы находятся в том же package components, поэтому Linux bridge непосредственно использует `ProbePackageSupervision`, `bootIdentity`, `processBirth`, `killSupervisorChildren`, `boundedPackageLog`. Export этих деталей для другого package не требуется; non-Linux bridge возвращает capability unavailable. Probe вызывается только в отдельном private helper, никогда внутри ordinary daemon: PR_SET_CHILD_SUBREAPER меняет весь процесс.

Bridge принимает approved immutable `Program`, `Args`, фиксированный environment, deadline и callback binding existing StrategyLab journal. CLI принимает только nonce/ID, не argv/path/PID. Intent до parent helper Start; armed + точный boot/start/identity supervisor durable до actual child Start. Parent и child Cmd.Start каждый проходят trusted StartAdmission, сериализованный с Stop; readonly StopCheck не разрешает запуск. Admission сохраняет installation ID вместе с sequence. Begin содержит только Cmd.Start, без Wait/fsync/Store locks. Lease StrategyLab descriptor остаётся у helper до durable terminal receipt + fsync.

Sole reap loop использует `syscall.Wait4(-1, ..., syscall.WNOHANG|syscall.WALL, ...)`, EINTR retry, ECHILD только после учёта direct child. Cmd.Wait не конкурирует с этим loop. WALL включает clone children с нестандартным exit signal; обычный WNOHANG этого доказательства не даёт. `/proc` PPID/birth scan — только exact child cleanup, никогда quiescence proof. Cancel/deadline принудительно маркируют результат rejected/cancelled даже при direct exit0; terminal known quiescent требует durable receipt с ECHILD. Missing receipt, helper death/crash, legacy schema2, foreign identity или corrupt receipt остаются durable unknown, без вывода из PID absence.

Минимальные bridge hooks: `Armed(identity) error`, `Started(directPID) error`, `Result(receipt) error`, `StartAdmission(begin func() error) error`, `StopCheck() error`. Ошибка durable Started после реального spawn требует cleanup + sole reap, но не success; ошибка Result/fsync не разрешает terminal success. NFQWS определяет собственные exported Command/Identity/Receipt DTO и typed journal binding без import cycle. CORE владеет fixed early CLI dispatch и binding admission; native execution выполняет Root. Это согласование reuse, не native acceptance NFQWS и не изменение ownership existing components files.

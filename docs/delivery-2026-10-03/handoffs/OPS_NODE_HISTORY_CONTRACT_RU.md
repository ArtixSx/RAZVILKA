# OPS → CORE: read-only retained node history gate

04.10.2026. Эта небольшая порция независима от незавершённого native self-update provider. Production self-update capability не включается.

`updatecheck.RequiredRetainedNodeHistoryReadVersion(ctx, configRoot, stateRoot, read)` возвращает максимальную необходимую версию reader, 1 либо 2. CORE передаёт `nodestore.RequiredPrivateHistoryReadVersion` из VLESS, а не bool из HTTP. Нулевой результат вместе с ошибкой означает unknown/corrupt/unavailable/cancelled; он никогда не разрешает downgrade. Roots — абсолютные trusted deployment roots; production `/opt/etc/razvilka` и `/opt/var/lib/razvilka`, независимо от местоположения одного live node Store.

Учитываются все `nodes.private.json` в этих roots, сохранённые private-snapshot.json с paired SHA и полным bounded registry, обе Before/After стороны retained restore.private.json. Журнал читается строго canonical/checksummed; неизвестный state, duplicate/case-folded/unknown fields, bad ID/order/image/bounds блокируют. Directory images учитываются, включая пустой tree. В каждой найденной node envelope вызывается typed reader с Content+SHA. Pending journal не recover/clear; Store/lock не открываются; backup не импортируется; expired Xray history остаётся capability2.

Предлагаемый fixed CLI CORE: `-check-node-history-state` читает trusted roots, сверяет свой `-node-history-read-version` с required и при успехе печатает ровно `{"ok":true}`; любой unknown/error/unsupported reader — nonzero, без private content в stderr. Upgrade/rollback должны вызывать target CLI до Stop и повторно после Stop, до первой replacement. Для Xray dispatcher CORE использует максимальную required capability и свою advertised reader version; очистка Xray history ради downgrade запрещена. Старый target без такого CLI fail closed при retained state. OPS подключит shell consumer после этого CLI.

Локальные Windows model tests проверяют максимум live/backup, обе restore стороны, пустой directory before, malformed/checksum/duplicate/future-state/incomplete snapshot/cancellation/unknown reader, byte-identical read-only live nodes. Они не являются native filesystem/power-cut acceptance. Полный provider, Stop journal и main wiring — отдельная следующая порция.

# RAZVILKA UI2 — единая панель

Дата: 8 сентября 2026. Локальный исходный кандидат на основе Autonomy A1 (`0.18.2-dev`, исходная база rc.2).

## Открыть интерфейс

Откройте `RAZVILKA_UI2.html` обычным браузером. Это отдельный интерактивный предпросмотр
того же DOM, стилей и контроллеров, что помещены в производственный сайт.
Коричневая полоса сверху обозначает искусственные данные. Все действия предпросмотра
остаются в памяти страницы, не меняют роутер, не скачивают подписки, не запускают туннели.
Недоступный вызов возвращает явную ошибку, а не фиктивный успех. Обновление страницы
восстанавливает примеры. В HTML нет приватных ключей, Recovery Token и встроенных шрифтов.

## Что находится в комплекте

- `RAZVILKA_UI2_SOURCE.zip`: весь проект A1 с единым новым основным интерфейсом UI2.
- `RAZVILKA_UI2_FROM_A1.patch`: изменения именно относительно исходников кандидата A1.
- `RAZVILKA_UI2_WEB.zip`: производственные файлы `web`, без демонстрационного транспорта.
- `RESEARCH_UI2_RU.md`: изученные интерфейсы и применённые принципы.
- `VALIDATION_UI2_RU.md`: фактические проверки и ограничения результата.
- `previews/`: снимки страниц на искусственных данных, включая телефон.
- `validation/`: автономно запускаемые браузерные проверки и подставные данные.

## Существенные изменения

Главная стала основным рабочим экраном: сервисы, фактические маршруты, ресурсные показатели,
график локального WAN-трафика, состояния компонентов и последние действия. В общей навигации
доступны 20 разделов; существующий редактор открывается в шести контекстах обходов.
Подписки отделены от узлов, журнал и обновления получили собственные страницы.
Мастер A1, его управление сервисами и расписания встроены сюда же. Старая ссылка
`/autonomy.html` перенаправляет в новую панель.

Сохранены все 568 исходных DOM ID и существующие API-контракты. Добавлены 32 SVG-символа,
сохранены исходные логотип и favicon. Тёмная/светлая темы, мобильная навигация, поиск Ctrl/Cmd+K,
клавиатурное управление и выделенные состояния ошибок не требуют внешних CDN и шрифтов.

Исправлены гонка перехода в редактор, затирание несохранённых полей при refresh,
неправильный option для всей LAN и селекторы дней недели в интегрированном мастере.
Добавлена общая обработка 401 и защита от позднего ответа после потери авторизации.

## Какие действия связаны с реальным backend

Производственные контроллеры вызывают штатные API для сервисов, узлов, подписок, проверок,
движков, устройств, DNS, диагностики и обновлений. Мастер и управление автономными сервисами
используют `/api/v1/autonomy` из A1. Подключение к backend без A1 явно запрещает сохранение
его политики, но не заменяет недостающий API фиктивными данными и не скрывает старые функции.

Проверка и подготовка ночных обновлений — не автоматическая установка. Последняя в A1 не
реализована. VMess/Trojan, новые аппаратные сценарии и бесшовная миграция соединений этим
обновлением не добавлены. Новые Go-функции относительно A1 в UI2 не создавались.

## Важное перед установкой

Это НЕ установочный Entware-пакет. Новых исполняемых файлов в комплекте нет.
В RAZVILKA сайт встроен в бинарник через `go:embed web/*`, поэтому копирование HTML/CSS
на установленный rc.2 само по себе не обновит сайт приложения. Нужны сборка новых исходников,
полные тесты и изолированный аппаратный прогон. Патч рассчитан на A1, не на чистый rc.2.

Полную сборку здесь выполнить не удалось: `go.mod` требует Go >=1.26.0, toolchain 1.26.5,
в окружении доступен 1.23.2. Файлы go.mod/go.sum и требования проекта не понижались.
Запуск существующего rc.2 для чтения API НЕ подтверждает сборку нового кандидата A1/UI2.

Репозиторий GitHub, опубликованные релизы и установленный роутер не изменялись.

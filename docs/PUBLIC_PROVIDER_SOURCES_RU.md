# Публичные источники VLESS

В панели автопилота пользователь выбирает разрешённый источник. Автопилот загружает кандидатов и проверяет через них целевой сервис. Для Telegram Web проверяется HTML-страница сервиса. Доступность публичного узла зависит от сети и времени наблюдения.

В аппаратной проверке rc.128 использовался VLESSforU. Другие источники требуют свежей проверки в сети пользователя. [Результат на NC-1812](CURRENT_STATUS_RU.md)

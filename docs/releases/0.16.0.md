# RAZVILKA v0.16.0

Крупное обновление надёжности установки и черновиков. Панель теперь явно
различает «доступен», «установлен», «установка проверена», «настроен» и
«запущен», а ошибка установки сохраняется на роутере и не исчезает после
обновления страницы.

## Главное

- Добавлены проверяемые receipts установки, обновления и удаления компонентов.
- Последняя ошибка или прерванная операция видна прямо в карточке обхода.
- Недоступный обход нельзя случайно включить; UI ведёт к установке нужного
  компонента.
- Для неиспользуемого черновика обхода доступны понятные действия: назначить
  сервис или удалить только этот черновик.
- Применение сервисов, устройств и конфигурации выбранного обхода разделено и
  не захватывает посторонние незавершённые изменения.
- README и bootstrap рассчитаны на чистый Entware, включая отсутствие `curl`
  или TLS-версии `wget`.
- Для Keenetic перечислены только три проверенные линии Entware: aarch64,
  mips и mipsel; amd64 обозначен как сборка для других систем.

## Безопасность обновления

Штатный установщик делает резервную копию, проверяет SHA-256, запускает
health-check и автоматически возвращает прежнюю версию при ошибке. Safe Mode
после установки остаётся включённым.

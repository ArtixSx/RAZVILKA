# Проверка v0.18.2-rc.5: выявлен отказ после первоначальной приёмки

Дата: 14 сентября 2026 года. Источник `3cabc9df9811d9ba0e8032de2f7c083e3a48dfea`.

Release 34808235192 и CI 34808235262 / 34808234904 прошли успешно.
Четыре бинарника опубликованы; официальный ARM64-архив установлен на Netcraze 6614.
Происхождение архива и точный commit проверены GitHub Attestations.

Первоначальные проверки подтвердили сохранение учётной записи и настроек,
отдельный перезапуск приложения, вход через браузер и cookie API. Все 12
проверенных запросов вернули HTTP 200: 16 сервисов, 351 узел, 6 файлов и 15
полей NFQWS2. Запрос сервисов занял 1,39 с вместо прежнего таймаута после
90 с. Многострочные стратегии отображались полностью; действующий конфиг
NFQWS2 не изменился. 25 ресурсов панели совпали с исходниками тега.
Минимальная длина пароля панели убрана; тесты коротких и точных паролей прошли.

После перезапуска два новых HTTPS-соединения выбранного ПК к Telegram
получили HTTP 200. Путь именно этих соединений был подтверждён через TUN,
с приростом RX 36875 и TX 3052 байта; правила во время проверки не менялись.

## Последующий отказ

При продолжении приёмки собственная цепочка RAZVILKA и её ссылки в таблице
`filter` исчезли полностью. Правила `nat`, процессы прокси, TUN и маршруты
сохранились, но новые клиентские соединения перестали проходить. Статус
`runtime-unverified` в этом наблюдении соответствовал реальному отказу.
Причина конкретной перезаписи таблицы отдельно не доказана.

rc.5 обнаруживает потерю этих объектов, но не восстанавливает их автоматически
при неизменном WAN. Исправление готовится в rc.6. Старый rollback и временные
файлы при отказе не удалялись; первоначальные успешные результаты не считаются
подтверждением длительной устойчивости. Это приложение не следует считать
полностью прошедшим аппаратную приёмку только по первоначальному HTTP 200.

## Границы проверки

На MIPS/MIPSel бинарники не запускались. Полная перезагрузка роутера,
WAN reconnect, IPv6 HTTPS, физический второй клиент и 24–72 часа работы
в rc.5 не проверялись. Проверка Telegram относится к указанным веб-сценариям.

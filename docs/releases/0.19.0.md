## Главное

- **Сервисы из списка NFQWS2 идут через NFQWS2 по умолчанию, как в z2k.** YouTube, Discord, Speedtest, Roblox, Riot Games и общий список взяты из списка nfqws2-keenetic; их штатный обход — NFQWS2. Автопилот:
  - возвращает такой сервис на NFQWS2, если назначенный ему узел пропал (подписка устарела, узел отключён или удалён), вместо поиска другого узла;
  - применяет ваш возврат сервиса на NFQWS2, если на роутере ещё действует старый маршрут через узел. Раньше автопилот считал это «ручным изменением» и вставал на паузу, а применения остальных сервисов ждали недоступный узел.
  - Работающий узел, выбранный вами, не заменяется; другие ручные изменения ждут вашего «Применить». NFQWS2 не ограничивается отдельными устройствами, поэтому автоматический возврат выполняется, когда автопилот работает на всю сеть.
- **Кнопка «Вернуть на NFQWS2».** Если применение ждёт сервис из списка NFQWS2 с недоступным узлом, уведомление предлагает вернуть его на NFQWS2 одной кнопкой.
- **Обновление используемых обходов с проверкой (M01).** Sing-box, Xray, USQUE и wireguard-tools теперь обновляются, как NFQWS2 в 0.18.19, без переноса сервисов: RAZVILKA сохраняет копию текущей версии, обновляет пакет и проверяет новую версию на ваших применённых маршрутах в изолированном пробном запуске (подготовка, проверка конфигурации, запуск на отдельном локальном порту). Действующие маршруты при этом не трогаются. При сбое возвращается прежняя версия. Работающие процессы переходят на новую версию при следующем применении или перезапуске. Неиспользуемый обход обновляется обычным способом и копии для отката не требует.

## Исправлено

- **Автопилот не останавливается после обновления списка.** В 0.18.19 список Discord расширился, и автопилот у тех, кто не пересохранял Discord, встал бы на «Состав сервиса изменился. Повторно подтвердите…». Изменения проверенного списка NFQWS2, поставляемые с RAZVILKA, теперь принимаются автоматически, а применённый маршрут переприменяется к новому составу. Изменения списков сообщества, своих сервисов и источников по-прежнему требуют подтверждения.
- **Список NFQWS2 соответствует nfqws2-keenetic 1.3.1.** Каталог был снят с 1.2.8. В 1.3.1 автор перенёс `roblox.com` и ещё четыре домена Roblox в список исключений, и RAZVILKA дописывала в список NFQWS2 домены, которые пакет не обрабатывает. Теперь группа Roblox содержит только CDN-домены. Тест сверяет каталог со списками upstream.
- **Общий список NFQWS2 больше не висит «не подтверждён».** Проверка шла на `cloudflarestatus.com`, который в России заблокирован по IP и не открывается через локальный обход. Теперь проверяется `www.cloudflarestatus.com` из той же группы.
- **DNS роутера.** KeeneticOS ждёт ответа DNS одну секунду и не повторяет запрос. Проверки сервисов, подписки, узлы и правила маршрутов теперь повторяют запрос при таймауте (до трёх попыток); ответ «имени нет» не повторяется. В README добавлены рекомендации по DNS роутера перед установкой.
- **Снимки обновлений больше не занимают сотни мегабайт.** Каждый снимок — около 50 МБ; после успешного обновления хранятся пять последних.
- **Прерванная фиксация транзакции досводится.** Если питание пропало после публикации зафиксированного плана, но до последней записи журнала, RAZVILKA больше не требует ручного восстановления журнала: этот доказуемый случай завершается при запуске. Остальные прерывания по-прежнему ограждаются.
- **Копия для отката.** Сохраняется при «Проверить версии», при ежедневной проверке компонентов автопилотом и сразу после установки или обновления, пока источник её предлагает. Раньше, если источник предлагал уже только новую версию, «Обновить с проверкой» блокировалось.

## Что проверить тестерам

Всё из заметок 0.18.18–0.18.19 (Xray, WireGuard · свой сервер, ремонт Discord) плюс:
- Назначьте сервису из списка NFQWS2 узел из подписки, затем отключите узел или удалите подписку. В течение нескольких минут автопилот должен вернуть сервис на NFQWS2, а остальные сервисы — примениться.
- «Обновить с проверкой» для используемого Sing-box, Xray или USQUE, когда в источнике есть новая версия.

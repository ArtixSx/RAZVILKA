# RAZVILKA 0.20.0 Test

Предварительная версия для проверки на своей сети. Номер сборки в панели —
`0.20.0-rc.62`. Она не заменяет стабильный выпуск; обычный канал обновлений
её пропускает. Тестовый канал предназначен для тех, кто выбрал его явно.

## Добавлено и исправлено

- В новых настройках первыми выбираются NFQWS2 и VLESS. Можно задать порядок
  разрешённых источников подключений; исправный путь сохраняется.
- На странице подключений разделены общий HTTPS-тест, проверка выбранного
  сервиса и TCP-пинг. Общий тест не включает маршрут и не заменяет проверку
  конкретного сайта. Его результат действует до пяти минут в той же сети.
- Автопилот временно пропускает узел после двух транспортных отказов общего
  теста, если после них другой узел успешно проверен тем же движком в той же
  сети. Пауза не превышает пяти минут; подключение сохраняется, ручная
  проверка остаётся доступной. Ошибка одного сайта не удаляет весь узел.
- Результаты операций показываются компактными уведомлениями с подробностями.
  Исправлены перенос длинных названий, карточки сохранённого каталога,
  обновление состояний сервисов и сообщение при потере связи с панелью.
- Устаревшая проверка не отображается как актуальный успех. В журнале
  различаются ошибки проверки узла, ограничения профиля и остановленный компонент.
- Для управляемого NFQWS2 доступны дополнительные варианты HTTPS-стратегии.
  Выбор сохраняется в черновике и применяется после отдельной проверки.
- Исправлено восстановление предыдущего профиля NFQWS2 после отмены или
  неудачного первого запуска. Неизвестный результат восстановления по-прежнему
  останавливает дальнейшие изменения сети.
- Уточнены отказы при неподдерживаемом переустановлении и сохранении настроек.

## Что учитывать при тестировании

- Основной стенд — ARM64, Netcraze Ultra NC-1812 с KeeneticOS
  `5.01.C.6.0-1` и Entware. MIPS и MIPSel собираются с soft-float;
  аппаратные проверки и управляемая маршрутизация для них пока не подтверждены.
- Управляемый профиль NFQWS2 рассчитан на доменные списки и HTTPS/TCP 443.
  Смешанный список «Telegram · домены и сети» этим профилем не поддерживается.
  Его применение через VLESS также ещё не реализовано. Не удаляйте домены
  или сети из списка для обхода этого отказа.
- VLESS остаётся экспериментальным: успешный запрос к сайту не подтверждает
  звонки, передачу файлов или все функции приложения. Общий быстрый отбор
  узлов ещё не включён в Автопилот.
- Обновление уже управляемого пакета NFQWS2 пока блокируется. WireGuard,
  AmneziaWG и WARP зависят от прошивки и конфигурации роутера.
- Исключения устройств NFQWS2 задаются политикой Keenetic. Для VPN и прокси
  применимость исключений зависит от IP-сетей сервиса; доменный список
  не превращается в общий маршрут к разделяемым адресам CDN.

## Установка тестовой версии

Нужны установленный Entware и SSH. Эта сборка устанавливается начисто;
обновление с 0.19.x или между предварительными сборками не поддерживается.
Перед удалением прежней установки сохраните нужные настройки. Порядок удаления
описан в [инструкции](https://github.com/ArtixSx/RAZVILKA/blob/v0.20.0-rc.62/docs/INSTALL_RU.md).

На подготовленном роутере без прежней установки RAZVILKA:

```sh
opkg update && opkg install curl ca-certificates ca-bundle
mkdir -p /opt/tmp
curl -fL --retry 2 \
  https://raw.githubusercontent.com/ArtixSx/RAZVILKA/v0.20.0-rc.62/scripts/bootstrap.sh \
  -o /opt/tmp/razvilka-test-rc62.sh && \
  RAZVILKA_VERSION=v0.20.0-rc.62 sh /opt/tmp/razvilka-test-rc62.sh
```

Откройте `http://192.168.1.1:8787` или адрес своего роутера с портом `8787`.
Используйте ключ первого входа, который выведет установщик. Начните с одного
сервиса и проверьте доступ с домашнего устройства. Причины отказов доступны
по кнопке «Лог · причины и действия».

Вложения содержат пакет Entware, отдельные бинарники и контрольные суммы SHA-256.

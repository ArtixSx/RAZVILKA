# RAZVILKA v0.15.1

Главное в этой версии — понятное и независимое применение изменений на разных
вкладках. Незаконченный профиль WARP больше не блокирует обычное изменение
Telegram, DIRECT или другого сервиса.

## Что изменилось

- На вкладках **«Сервисы»** и **«Устройства»** появились собственные кнопки
  проверки, применения и отмены текущих маршрутов.
- Применение сервисов включает только те черновики обходов, которые реально
  используются выбранными маршрутами. Остальные черновики сохраняются отдельно.
- Настройка движка применяется только для выбранного движка и не поглощает
  незаметно несвязанные изменения сервисов.
- Неустановленные обходы видны в списке для понимания возможностей, но выбрать
  их как новый рабочий маршрут нельзя.
- Telegram проверяется несколькими обязательными сценариями и включает
  официальные IPv4/IPv6 сети для случаев полной IP-блокировки.
- Усилена доказательность маршрутов: DIRECT используется как контроль, Smart
  Route разделяет результаты разных WAN, а неподтверждённый маршрут не выдаётся
  за рабочий.
- Добавлены DNS-профили и безопасный preview-план. Живое изменение DNS пока
  намеренно не включено до аппаратной проверки rollback.
- Добавлены локальный журнал действий, Recovery Safe Mode, защита от boot-loop,
  проверка конфликтов портов/NFQUEUE/policy routing и ограниченные тайм-ауты.

## Установка и обновление

```sh
curl -fsSL https://raw.githubusercontent.com/ArtixSx/RAZVILKA/main/scripts/bootstrap.sh | sh
```

Установщик определит архитектуру, проверит SHA-256, сохранит резервную копию и
покажет локальный адрес с одноразовым ключом первого входа. После входа задайте
собственный логин и пароль.

## Важно

- Safe Mode остаётся включённым по умолчанию.
- WARP зависит от доступности Cloudflare в конкретной сети. При неподтверждённом
  handshake RAZVILKA выполняет rollback; для устойчивого полного туннеля можно
  использовать Sing-box/VLESS или AmneziaWG со своим сервером.
- Перед обновлением рекомендуется экспортировать резервную копию.

# RAZVILKA 0.18.0 — автопилот и честная проверка обходов

Крупное стабильное обновление упрощает ежедневную работу с сервисами и
исправляет аппаратную ошибку NFQWS2 на Entware.

## Главное

- **Исправлен NFQWS2.** Списки доменов и IP теперь доступны процессу, который
  после запуска работает от `nobody`. RAZVILKA дополнительно проверяет, что
  NFQWS2 не просто напечатал `Started`, а действительно остался запущенным.
- **Добавлен Автопилот для AUTO-сервисов.** Он с ограниченной частотой сравнивает
  текущий маршрут, DIRECT-контроль и одну альтернативу. Новый путь применяется
  только после подтверждённой проверки и через штатный rollback-контур.
- **Один понятный Apply.** На вкладке «Сервисы» больше нет одновременно общего,
  локального и модального подтверждения. Для обычного изменения остаётся
  «Сохранить и проверить»; подробный экран появляется только при блокере или
  крупном изменении.
- **Sing-box получил автоматический пул.** При импорте нескольких
  VLESS/Reality, Hysteria2, TUIC или Shadowsocks-узлов Sing-box локально
  проверяет до 16 кандидатов и выбирает доступный. Все узлы остаются доступны
  для ручного выбора.
- Ссылка на сайт публичного чекера больше не принимается за профиль. Нужно
  вставить сам ключ или список ключей. Проверка открытого TCP-порта не считается
  доказательством VLESS/TLS/Reality handshake.

## Что проверено на Keenetic ARM64

- транзакционное обновление `0.17.0 → 0.18.0-rc.1` с сохранением учётной записи,
  конфигурации и рабочего dataplane;
- NFQWS2 остаётся запущенным, его runtime-списки имеют права `0644`;
- YouTube `generate_204` через применённый NFQWS2-маршрут отвечает `HTTP 204`;
- конфигурация Sing-box `selector + urltest` проходит нативную проверку
  установленным Sing-box `1.13.3`;
- полный набор Go-тестов, `go vet` и синтаксическая проверка JavaScript.

## Важно о публичных ключах

Публичный ключ может устареть между публикацией и установкой. RAZVILKA не
обещает работоспособность стороннего сервера: она проверяет кандидат изолированно
и не меняет рабочую сеть при отказе. Для стабильной полной блокировки
рекомендуется собственный или доверенный сервер.

## Обновление

Повторно запустите команду установки с главной страницы. Установщик сверит
SHA-256, сохранит настройки, создаст резервную копию и автоматически вернёт
предыдущую версию при ошибке запуска или health-check.

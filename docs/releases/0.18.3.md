# RAZVILKA 0.18.3

## Добавлено

- Мастер Автопилота: выбор сервисов, устройств, источников и расписания проверок.
- Браузер подключений с названиями стран, проверкой узлов и разрешённым резервом.
- Каналы обновлений приложения, подготовка архива и пополнение подписок.
- Экспорт конфигурации Mihomo, экспериментальный генератор профиля HEV и ручной обмен пакетами стратегий NFQWS2.

## Исправлено

- Ложный отказ проверки сервисов при больших HTML-ответах, когда сайт игнорирует Range. Проверки JSON и блокировок сохранены.
- Включённый по умолчанию автозапуск примерной конфигурации Sing-box после установки пакета.
- Загрузка панели, многострочное редактирование NFQWS2 и ограничения минимальной длины пароля.
- Сохранение выбора в мастере, перечитывание настроек после записи, сообщения после входа и загрузка файлов.
- Потеря обязательных параметров при преобразовании профилей, подписи и размер пакетов стратегий.
- Очередь проверок, сохранение ошибок очистки и восстановление исчезнувших собственных правил маршрута.

[Подробные проверки и ограничения](https://github.com/ArtixSx/RAZVILKA/blob/main/docs/EXT5_REVIEW_2026-09-19_RU.md).

## Главное

- **Обновляется сама ночью.** Новый стандартный режим окна обслуживания — «Устанавливать сама, с откатом при сбое». В окне RAZVILKA ставит новую стабильную версию с проверенной подписью. Если после установки что-то не работает, установщик возвращает прежнюю версию, и эту версию сама больше не ставит. Используемые обходы (движки) обновляются с проверкой на маршрутах и откатом. Новые установки получают этот режим сразу; на уже настроенных роутерах режим выбирается в «Правилах автопилота → Обслуживание».
- **Обновление больше не оставляет роутер с «незавершённым откатом».** При установке 0.19.2 на роутере владельца автопилот начал применение узла раньше, чем после перезапуска вернулись списки NFQWS2, и его откат не смог подтвердиться: панель встала в защиту журнала, Telegram шёл без узла, YouTube и Discord — без обхода. Исправлено:
  - после любого перезапуска NFQWS2 восстанавливается сразу, не дожидаясь перепроверки узлов (узлам она по-прежнему нужна);
  - откат NFQWS2 возвращает управляемый блок списков, если он доказуемо совпадает с записанным в манифесте;
  - незавершённый откат повторяется сам при запуске, с теми же строгими проверками; журнал закрывается только при точном восстановлении, иначе защита остаётся;
  - ручной повтор (`-retry-rollback-plan`) работает и в безопасном режиме восстановления, который сам включается при таком запуске;
  - точное восстановление состояния, в котором движок был остановлен, закрывает журнал как «откат без живого подтверждения» — так же, как обычный откат.
- **Все методы перед подбором узла.** В «Правила автопилота → Предпочитаемые методы перед подбором узла» теперь все обходы с проверкой: NFQWS2, WARP · MASQUE, WARP · WireGuard, AmneziaWG, WireGuard, Sing-box и Xray (свои серверы). Автопилот пробует отмеченные по порядку и оставляет первый, прошедший проверку сервиса; неустановленные и ненастроенные пропускаются. Уже сохранённый выбор не меняется: новые методы отмечаются вручную.

## Проверено на роутере

- Незавершённый откат 0.19.2 закрыт исправленной программой: блоки NFQWS2 вернулись, откат подтверждён для NFQWS2, панель запустилась без защиты журнала, восстановление при запуске вернуло NFQWS2 сразу, автопилот сам применил узел для Telegram.

# RAZVILKA 0.20.0 Test

Тестовая сборка `0.20.0-rc.66`. Она не заменяет стабильный выпуск.

## Исправлено

- Остановка управляемого NFQWS2 проверяет ранее применённый профиль.
  Пустой список после остановки больше не принимается за новый профиль запуска.
- Проверка NFQWS2 требует действующего правила направления трафика именно
  в его очередь. Работающий процесс и посторонние очереди роутера больше
  не считаются подтверждением готовности обхода.
- Ручные профили NFQWS2 с политиками Keenetic, своими TCP-портами и UDP
  проверяются по соответствующим правилам. Они больше не проверяются как
  упрощённый профиль первого запуска для TCP 443.
- В диагностике восстановления NFQWS2 уточнён этап отказа при чтении процессов.
  Неизвестное состояние по-прежнему останавливает дальнейшие изменения.
- После таймаута первого сервера проверки внешнего IP VLESS может проверить
  резервный сервер в пределах общего лимита времени. Сохраняются проверки
  прямого и проксируемого соединения; это не гарантирует исправность самого узла.
- Пустые доменные и IP-списки NFQWS2 больше не препятствуют резервному копированию.
  Их содержимое, включая комментарии, сохраняется без изменений.
- Устранён запрет по номеру версии для будущего перехода с этой и следующих
  тестовых сборок на более новую версию. Тестовый канал по-прежнему выбирается
  явно; проверки совместимости, сохранения состояния и отката остаются обязательными.

## Установка

Для перехода с `rc.63` и более ранних сборок нужна чистая установка: их
установленный обновлятор не содержит нового исправления. Сохраните настройки
перед удалением; используйте [инструкцию](https://github.com/ArtixSx/RAZVILKA/blob/v0.20.0-rc.66/docs/INSTALL_RU.md).

На роутере с Entware и без прежней установки RAZVILKA:

```sh
opkg update && opkg install curl ca-certificates ca-bundle
mkdir -p /opt/tmp
curl -fL --retry 2 \
  https://raw.githubusercontent.com/ArtixSx/RAZVILKA/v0.20.0-rc.66/scripts/bootstrap.sh \
  -o /opt/tmp/razvilka-test-rc66.sh && \
  RAZVILKA_VERSION=v0.20.0-rc.66 sh /opt/tmp/razvilka-test-rc66.sh
```

Откройте `http://192.168.1.1:8787` или адрес своего роутера с портом `8787`.
Используйте ключ первого входа, который выведет установщик.

## Ограничения тестовой версии

- NFQWS2 рассчитан на доменные списки и HTTPS/TCP 443. Если прошивка удалит
  его правила, панель сообщит о неготовности; автоматическое восстановление
  правил после такого события ещё не реализовано.
- Смешанные списки доменов и сетей, включая «Telegram · домены и сети», пока
  не поддержаны управляемым исполнителем NFQWS2 или VLESS.
- VLESS остаётся экспериментальным. TCP-пинг не подтверждает работу туннеля,
  а общий HTTPS-тест не подтверждает все функции выбранного сервиса.
- Обновление уже управляемого пакета NFQWS2 пока блокируется. Работа WireGuard,
  AmneziaWG и WARP зависит от прошивки и профиля.
- MIPS и MIPSel собираются с soft-float; проверки на физических устройствах
  этих архитектур ещё не выполнены.

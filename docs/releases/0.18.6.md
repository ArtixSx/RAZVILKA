# RAZVILKA 0.18.6

## Добавлено

- Установка на готовый Entware в две команды с подготовкой нужных утилит.
- Отдельные команды удаления панели и отката обновления.
- Краткая главная страница с баннером и инструкциями для AArch64, MIPS и MIPSel.

## Исправлено

- Удаление после обновления больше не возвращает предыдущую версию панели.
- Проверка инструментов для запуска службы и распаковки архива на чистом Entware.
- Установка на Entware, где `/opt` является ссылкой на накопитель.
- Проверка путей архива при распаковке через BusyBox.
- Устаревшие инструкции кандидатов перенесены в архив документации.

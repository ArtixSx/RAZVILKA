# RAZVILKA v0.18.2-rc.2

Кандидат первого доступного предварительного выпуска DC1 для общего тестирования.
`v0.18.2-rc.1` не был опубликован: его выпускной прогон остановился на тесте
отмены WARP. Тег сохранён, а `rc.2` проходит отдельную выпускную проверку.
Объединяет исходную историю GitHub и восстановленную историю пользовательского
архива. Стабильный канал `latest` остаётся на v0.18.0.

## Что изменилось

- Тёмная тема по умолчанию, заметные вкладки «Главная» и «Автопилот», более
  понятный первый запуск, карточки сервисов и навигация на телефоне.
- Исправлено восстановление собственного туннеля: успешный отдельный тест
  узла больше не скрывает остановку рабочего процесса.
- Исправлены сроки задач в очереди, проверки совместимости AmneziaWG и
  отмена устаревших операций между этапами применения.
- Уточнена проверка настоящих DNS-ответов; поздние ответы после отмены,
  изменения настроек или выхода из панели не отображаются как текущие.
- Исправлены повторный вход и устаревшие ответы авторизации, сохранение
  пользовательского DNS, неоднозначные поля в подписках и рекомендациях.
- Установщик требует единственную правильную SHA256-запись до запуска
  нового бинарника. Версия интерфейса и ключи кэша согласованы с выпуском.
- Обновлены README, текущий статус и план; исходные отчёты импорта явно
  обозначены как исторические.

## Установка и обновление

Для Keenetic/Netcraze с Entware используйте `RAZVILKA-entware.tar.gz` и
расположенный рядом файл `.sha256`. Внутри находятся четыре сборки:
`arm64` (aarch64), `mipsle` (mipsel), `mips` и `amd64`.
Штатный установщик выбирает подходящую архитектуру.

После публикации файлов выпуска в уже скачанном и проверенном
`scripts/bootstrap.sh` закрепите версию:

```sh
RAZVILKA_VERSION=v0.18.2-rc.2 sh bootstrap.sh
```

Подробные команды загрузки и установки — в [README](../../README.md).
Панель по умолчанию: `http://192.168.1.1:8787`.
Перед обновлением сохраните полную приватную копию данных текущей установки.
Для объединения двух установок нельзя просто смешивать их активные журналы
маршрутов: сначала требуется штатная остановка и перенос настроек.

## Проверка и ограничения

Release workflow публикует архивы только после полного Linux-прогона:
Go tests/race/vet, проверки интерфейса, четыре сборки и Entware-транзакции.
Точные результаты проверки опубликованных бинарников на роутере и контрольные
суммы приведены в приложенном к выпуску `VALIDATION_RU.md`.

DNS-лаборатория пока сравнивает ответы A/AAAA. Сквозная проверка пары
«DNS + выбранный обход + сервис», её применение в ограниченной области и
автоматический подбор пары остаются этапами DC2–DC4. Облачный каталог и
отправка результатов не включены. Успех DNS или запуск процесса не являются
доказательством доступности всех функций сайта.

Этот выпуск не закрывает аппаратную проверку всех моделей, MIPS/MIPSel,
перезагрузки роутера и непрерывной работы 24–72 часа.

# RAZVILKA 0.20.0 Test

Тестовая сборка `0.20.0-rc.72`. Она не заменяет стабильный выпуск.

## Добавлено

- Восстановление ранее применённых правил NFQWS2, если прошивка роутера
  удалила их, а управляемый процесс продолжает работать. Панель проверяет
  профиль, процесс, очередь и обе версии IP перед восстановлением.
- Фоновая проверка разрешённых подключений VLESS. Узлы, недавно прошедшие
  общий HTTPS-тест, получают приоритет при следующем подборе для сервиса.
  Проверки выполняются по одному, с паузами и ограничением нагрузки.

## Исправлено

- Ссылки VLESS с одинаковыми безопасными значениями `allowInsecure` и `insecure`
  больше не отклоняются из-за повторения параметра. Противоречивые значения
  и отключённая проверка сертификата по-прежнему запрещены.
- Короткие VLESS ID поддерживаются по правилам Xray и преобразуются в одинаковый
  UUID для Sing-box и Xray. Исходные данные подключения не попадают в предпросмотр.

- Ожидание незавершённого ответа при проверке VLESS корректно определяется
  как тайм-аут ответа, а отмена не записывается как отказ узла.

- Ошибка создания правила больше не даёт права удалить совпавшее чужое
  правило при откате. Неизвестный результат сохраняется для диагностики,
  в том числе после перезапуска панели.
- Пауза Автопилота и отзыв разрешения на источник отменяют текущую фоновую
  проверку. Поздний ответ не возвращает отозванное подключение в очередь.
- Фоновый подбор использует выбранный совместимый движок: обычный VLESS
  проверяется и при наличии только Xray.
- Задержка повторной попытки NFQWS2 отсчитывается после завершения предыдущей
  операции. Долгая проверка больше не съедает эту паузу.
- Неопределённый результат проверки, занятый исполнитель или отмена операции
  больше не расходуют попытки поиска как подтверждённый отказ сервиса.
- Диагностика подключения уточняет этап задержки: соединение с узлом,
  проверка выхода в интернет или проверка сервиса.

## Установка

Перед заменой прежней установки сохраните настройки. Порядок чистой
установки и удаления описан в [инструкции](https://github.com/ArtixSx/RAZVILKA/blob/v0.20.0-rc.72/docs/INSTALL_RU.md).

На роутере с Entware и без установленной RAZVILKA:

```sh
opkg update && opkg install curl ca-certificates ca-bundle
mkdir -p /opt/tmp
curl -fL --retry 2 \
  https://raw.githubusercontent.com/ArtixSx/RAZVILKA/v0.20.0-rc.72/scripts/bootstrap.sh \
  -o /opt/tmp/razvilka-test-rc72.sh && \
  RAZVILKA_VERSION=v0.20.0-rc.72 sh /opt/tmp/razvilka-test-rc72.sh
```

Откройте `http://192.168.1.1:8787` или адрес своего роутера с портом `8787`.
Ключ первого входа выведет установщик.

## Ограничения

- Автоматическое восстановление NFQWS2 относится к управляемому профилю
  первого запуска для HTTPS/TCP 443. Изменённый или неоднозначный набор правил
  требует проверки; панель не перезаписывает его принудительно.
  Если панель перезапущена уже после утраты правил, действует проверка
  восстановления при запуске: при отказе обход останавливается и требуется
  проверка причины перед повторным включением.
- Общий HTTPS-тест VLESS помогает сократить подбор, но не подтверждает
  доступность всех функций конкретного сервиса. Публичные узлы нестабильны.
- Смешанные списки доменов и IP-сетей пока не поддержаны управляемым
  исполнителем. Для Telegram через VLESS используйте определение сервиса
  с сетями Telegram.
- Обновление уже управляемого пакета NFQWS2 пока блокируется. WireGuard,
  AmneziaWG и WARP остаются экспериментальными.
- Сборки MIPS/MIPSel используют soft-float. Проверки на физических роутерах
  этих архитектур ещё не выполнены; управляемые маршруты для них недоступны.

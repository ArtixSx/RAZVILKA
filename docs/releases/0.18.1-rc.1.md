# RAZVILKA 0.18.1-rc.1 — достоверные проверки обходов

**Предварительная сборка для проверки.** Стабильной рекомендованной версией
остаётся [0.18.0](https://github.com/ArtixSx/RAZVILKA/releases/tag/v0.18.0).
Эта сборка не заменяет её в автоматическом выборе последнего стабильного релиза.

## Что изменилось

- Проверки больше не считают успехом страницу блокировки с кодом 200,
  перенаправление на посторонний сайт, ответы 403/451 или неверное содержимое.
  Для YouTube требуется ожидаемый HTTP 204; это проверка соединения, не видео.
- Результаты разделены: сервис работает, ответ ограничен, ошибка проверки,
  недостаточно данных или ответ пришёл через другой маршрут.
- Для управляемых Sing-box, Xray и USQUE добавлено локальное подтверждение
  процесса, конфигурации и владельца SOCKS-порта. Один ответ прокси больше
  не доказывает использование выбранного обхода.
- DIRECT вместо удалённого узла, изменённый профиль и чужой прокси-порт не
  получают ложное подтверждение. Автопилот отзывает устаревший успех маршрута.
- Исправлено зависание SOCKS-проверок: отмена и тайм-аут действуют на всех
  этапах подключения. При неудачном запуске завершается созданный тестом процесс.
- В настройках согласованы версия, commit и дата сборки; актуализированы
  матрица возможностей и план разработки.

## Важные ограничения

- Аппаратная приёмка этой версии на роутере ещё не завершена. Результаты CI
  не равнозначны подтверждению работы всех обходов в вашей сети.
- Сложные URLTest/selector-пулы и цепочки, а также старые/сторонние процессы
  без записи управляемого запуска могут показывать «Путь не подтверждён».
  Это не означает, что сервис не работает. Профили не переписываются и
  сторонние процессы не перезапускаются автоматически.
- Локальное подтверждение процесса не заменяет независимую проверку
  удалённого выхода. Воспроизведение YouTube, MTProto и звонки Telegram
  не объявляются проверенными одной веб-проверкой.
- Успешная работа WARP WireGuard в ранее проблемной сети этой сборкой
  пока не подтверждена.

## Проверка сборки

Release workflow запускает Go-тесты на Linux, race detector, статическую
проверку, UI-тесты, сборки и тест транзакционной установки до публикации файлов.
Подробности: [GitHub Actions](https://github.com/ArtixSx/RAZVILKA/actions).

## Установка для тестирования

Используйте архив **RAZVILKA-0.18.1-rc.1-entware.tar.gz** ниже. Сначала
выполните `sh scripts/upgrade-entware.sh --dry-run`, затем при успешной
проверке — `sh scripts/upgrade-entware.sh --apply` из распакованного каталога.
Сохраните путь резервной копии, напечатанный установщиком, для отката.

Соответствие файлов роутерам с Entware:

- aarch64 → `razvilka-linux-arm64`;
- mips → `razvilka-linux-mips`;
- mipsel → `razvilka-linux-mipsle`.

Сборка amd64 предназначена для отдельного Linux-стенда, не для Keenetic.
Контрольные суммы приложены к файлам релиза.

# RAZVILKA 0.20.0-rc.128

Тестовый выпуск для Keenetic и Netcraze с Entware. Основная проверенная платформа — Netcraze NC‑1812, ARM64.

## Что видно в панели

- В **Сервисах** и списке автопилота уточняется, какой из одноимённых сервисов встроенный, а какой пользовательский. У каждой записи остаются собственные настройки и результаты.
- Автопилот может загрузить публичный список VLESS, проверить конкретный сервис и продолжить подбор после отказа узла. Состояние проверки и состояние маршрута показаны отдельно.
- В реальном испытании Telegram Web первый узел вовремя не ответил, второй вернул HTTP 200 и страницу с ожидаемым содержимым. Подбор занял 2 мин 42 с. Проверенный узел появился в резерве. В том же прогоне завершилась штатная остановка из панели, сохранилась возможность возобновления.

## В процессе

1. **Обход для всей сети Home с исключениями устройств и их собственными VPN-политиками.** На испытании rc.128 маршрут на весь дом оставался выключенным. Проверки Telegram Desktop, звонков и медиа — отдельные сценарии.
2. **HEV на AMD64.** Для этого дополнительного компонента клиент ожидает специальный файл от проекта по зарезервированному адресу выпуска `v0.20.0`. В комплекте rc.128 этого файла нет. На ARM64 используется отдельная закреплённая сборка HEV 2.17.1 от разработчика компонента.

RAZVILKA 0.20.0 — новая база проекта

RAZVILKA — локальная панель для Keenetic и Netcraze с Entware. Вы выбираете
сервисы, а панель управляет их подключениями и показывает, что действительно
проверено на вашем роутере. Расписания работают и при закрытом браузере.

Что изменилось

• Переработан интерфейс: тёмная тема, простой режим для повседневного
  использования, расширенные настройки, мастер первого запуска, страницы
  сервисов, подключений, исключений и событий.
• В каталоге собраны готовые определения сервисов; можно добавить свой сайт.
  Перед импортом виден состав доменов и сетей, источник и конфликты.
  Резервный список явно отмечается как снимок, если источник недоступен.
• У своих сервисов появилась кнопка удаления. Сначала снимаются их маршруты,
  затем удаляются настройки; остальные сервисы сохраняются.
• Автопилот загружает разрешённые источники, проверяет кандидатов и сохраняет
  пригодный путь. Поиск первого VLESS теперь чередуется с обычными проверками,
  чтобы новый сервис меньше ждал в общей очереди. Работающий узел не меняется
  только ради меньшего пинга; новый путь проходит проверку перед применением.
• Подключения показаны понятными карточками: страна из подписи источника,
  параметры и результат проверки. Низкий пинг отдельно не считается
  подтверждением доступности нужного сервиса.
• В каталог добавлен Telegram через VPN или прокси: только официальные
  IP-сети Telegram, без перенаправления посторонних сайтов на общих адресах.
• NFQWS2 впервые устанавливается остановленным. Штатные широкие правила
  пакета не включаются раньше профиля выбранных сервисов.
• Исправлены зависшие статусы, сжатие длинных названий, двойное открытие лога
  и ряд ошибок восстановления. Лог отдельно показывает причины отказов,
  проверки Автопилота и ручные действия; сохранённые данные имеют отметку
  о давности.
• Переработаны установка, остановка и удаление. Данные и настройки отделены
  от программы; при удалении с очисткой они переносятся в закрытую папку.
  Обновления новой линейки выполняются через панель с журналом и снимком.
  Подтверждённый сбой вызывает откат; неизвестный результат требует проверки.

Как устроен обход

В основном режиме правила действуют для выбранных сервисов во всей домашней
сети. Остальной интернет использует обычный маршрут роутера, включая уже
настроенный отдельный VPN. Пустой список не означает обход всего Интернета.

Для доменных списков используется NFQWS2. VLESS и другие VPN/прокси работают
с сервисами, заданными IP-сетями. Так один общий IP CDN не превращается
в обход всех размещённых на нём сайтов.

Исключения сайтов и поддоменов поддерживаются NFQWS2. Для маршрута по IP
нужно исключить адрес, сеть или сервис; конфликт останавливает применение.
Исключения устройств для NFQWS2 задаются штатной политикой Keenetic.

Перед установкой

0.20.0 — чистая установка, без переноса настроек 0.19.3 и старее.
Сначала удалите старую версию по инструкции, затем установите новую.
Понадобятся Entware, SSH и работающий DNS на роутере.

Основной аппаратный стенд — Netcraze Ultra NC-1812, ARM64. Для MIPS/MIPSel
сборка программы не означает поддержку управляемых маршрутов: они пока
недоступны. Режим отдельных устройств экспериментальный; WARP, WireGuard
и AmneziaWG имеют ограничения, перечисленные в документации. Автообновление
управляемого NFQWS2 пока заблокировано до завершения проверки сохранения
его настроек. Бесплатные VLESS-источники могут переставать работать;
проверять их нужно из своей сети.

## Главное

- **Новая чистая база.** 0.20.0 ставится начисто: настройки — в `/opt/etc/razvilka`,
  рабочие данные — в `/opt/razvilka`. Обновления 0.20+ идут только через панель,
  с журналом, снимком и откатом. Установщик не ставится поверх 0.19.x и старее —
  [порядок перехода](../INSTALL_RU.md#переход-с-0193-и-более-ранних-версий).
- **Только включённые сервисы.** Обход действует лишь для сервисов из активного
  списка; исключённые устройства и сайты, а также весь остальной интернет идут
  обычным маршрутом роутера, включая ваш собственный VPN.
- **Чужие сайты не перехватываются.** Сервисы, заданные доменами, больше не
  превращаются в IP-маршруты через VPN или прокси — на одном IP работают и
  посторонние сайты. Для таких сервисов используется NFQWS2: он проверяет имя
  сайта в каждом соединении. VLESS, WireGuard и WARP обслуживают сервисы,
  заданные IP-диапазонами.
- **«Сайты без обхода» для NFQWS2.** Сайты, IP-адреса и сервисы из списка
  «Исключения → Сайты без обхода» NFQWS2 не обрабатывает (домен — вместе с
  поддоменами). Если исключённый адрес или сервис попадает в маршрут через
  VPN или прокси, применение остановится с объяснением, а не пропустит его в
  обход. Маршрут по IP-сетям не различает домены: для сайта внутри таких сетей
  исключите его IP-адрес. Кнопка «Применить исключения» появляется, когда
  сохранённый список меняет работу обхода.
- **Telegram через VPN или прокси.** В каталоге есть сервис «Telegram · через
  VPN или прокси» — только официальные IP-сети Telegram, без доменов: его можно
  вести через VLESS, WireGuard или WARP, не захватывая чужие сайты.
- **Понятные отказы.** Если выбор нельзя применить в текущем режиме, панель и
  автопилот показывают причину и что сделать, без бесконечных повторов.
- **Удаление с нуля.** `--uninstall --purge` переносит все данные в отдельную
  папку, чтобы установить RAZVILKA заново.

## Ограничения

- Режим «Домашняя сеть» (обход только для выбранных устройств) —
  экспериментальный: пока работает только на Netcraze Ultra (NC-1812) с прошивкой
  5.01.C.6.0-1 и обслуживает один сервис с IP-диапазонами. Основной режим — вся сеть.
- Устройства без обхода для NFQWS2 задаются политикой доступа Keenetic
  («Исключения → Настройки исключений NFQWS2»); для VPN и прокси устройства
  выбираются в карточке сервиса.
- Пакет USQUE не устанавливается и не обновляется при пересечении его
  автоматических адресов `172.16.1.100–172.16.1.200` с локальными адресами или
  сетями. Уже работающий штатный USQUE тоже может вызвать защитный отказ;
  перед повтором нужно проверить настройки пакета.
- Сборки MIPS и MIPSel не проверялись на физических роутерах.
- Состояния «настроено», «применено» и «сервис доступен» — разные проверки;
  запущенный процесс не доказывает работу обхода.

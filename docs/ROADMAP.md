## Следующие шаги

Происхождение, все SHA256, установка и A/B точного GitHub-бинарника `5fceff8`
подтверждены отдельно; два из шести узлов получили сервисный PASS.
Последующий перезапуск 0.18.4 не принят из-за старого backoff восстановления;
неопубликованный черновик сохранён и удалён, тег оставлен. Финальная очистка прошла.

1. Проверить автоматическое восстановление при намеренном отказе основного узла,
   WAN reconnect/reboot и настоящий второй LAN-клиент.
2. Расследовать прерывистый сброс наблюдателя на локальной и итоговой сборках:
   откат с восстановлением исходной сети подтверждён, причина сброса неизвестна.
   Повторить проверку устойчивости
   на 24–72 часах, IPv6/UDP и малопамятных MIPS/MIPSel.
3. Завершить адресный DNS с TTL по доменам, проверкой DNS + маршрут + сервис
   и применением только к выбранным клиентам.
4. Подписанные совместимые обновления приложения и зависимостей с полным откатом;
   нативная интеграция Mihomo/HEV; онлайн-обновления проверенных стратегий.
5. Отдельно оценить поддержку OpenWrt: пакет, `procd`, UCI, firewall4/nftables,
   определение модели и испытания на настоящем устройстве. Текущий установщик
   остаётся предназначенным для трёх Entware на Keenetic / Netcraze.

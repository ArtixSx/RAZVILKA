# План развития RAZVILKA

Обновлено 23 сентября 2026 года. Действующий план —
[единая переработка панели, автоматики и домашней сети](plans/unified-lan-2026-09-22/README.md).
База — исходники 0.18.10 (`c3722365`). Незавершённые требования прежних планов
сохранены; старые архивы поверх проекта повторно не накладываются.

## Ближайший результат

Панель остаётся доступной при долгой проверке или восстановлении. Автопилот и
его состояние видны на главной, сервис управляется из одной карточки, разделы
загружаются независимо. Доступность панели и работоспособность сайта различаются.
Первый патч перенесён в отдельную рабочую копию; результаты и оставшаяся приёмка —
в [отчёте перехода](plans/unified-lan-2026-09-22/INTAKE_RU.md).

## Порядок работы

| Этап | Результат | Проверка |
| --- | --- | --- |
| U0 — интерфейс и перенос | Шесть разделов, Автопилот на главной, проверка в карточке | Полный CI, настоящий вход и HTTP-сервер, desktop/mobile, сохранённые настройки |
| U1 — доступная панель | Состояние читается во время долгой операции | Согласованные снимки с возрастом; чтение не меняет сеть |
| U2 — серверные задания | Работа продолжается при закрытом браузере | Перезапуск, отмена, потерянный ответ, повторный клик, приоритет Stop и отката |
| E1 — домашняя сеть | Все домашние устройства, кроме исключённых; общие исключения сайтов | Единые правила для обходов и DNS; прежний охват сохраняется при обновлении |
| D1 — DNS/Smart DNS | Проверяемая комбинация DNS и подключения | Точный IP, исходное имя/TLS, выбранный и исключённый клиент, применение и откат |
| U3 — восстановление | Рабочий резерв после подтверждённого отказа | A отказал → B не применился → проверенный откат → C работает; другой клиент не затронут |
| U4 — каталоги и подписки | Списки доступны без GitHub; резерв пополняется небольшими партиями | Постоянный снимок, импорт просмотренной версии, 304, 33-й узел, частичный отказ |
| U5 — NFQWS2 | Подбор совместимой стратегии выбранного сервиса | Видимость пакетов, медиасценарии, сохранение личных списков и исключений |
| U6 — WARP/USQUE и исполнители | Повторное использование регистрации, проверяемые H3/H2 и зависимости | Реальные TCP/UDP-пути; DNS и экспорт не создают новый аккаунт |
| U7 — автообслуживание | Разрешённые обновления по расписанию | Проверка происхождения/совместимости, независимый возврат при незапуске панели |
| U8 — выпуск | Предсказуемая работа поддерживаемых роутеров | Точные сборки, два клиента, IPv6/UDP, перезапуски и 24/72 часа наблюдения |

E1 проектируется вместе с U1/U2, исполнение — вместе с ранним D1.
DNS не откладывается до появления новых движков. Соответствие прежним задачам —
в [таблице перехода](plans/unified-lan-2026-09-22/source/docs/PLAN_CROSSWALK_RU.md).

## Домашняя сеть и исключения

«Все домашние устройства» и «Весь интернет через туннель» — разные настройки.
Основной предлагаемый режим обслуживает выбранные сервисы в выбранных домашних
сегментах. Гостевые и VPN-сегменты не добавляются автоматически.

Исключённое устройство не использует обходы и сервисный Smart DNS RAZVILKA.
Ручные правила сохраняются при обновлениях. Российский список строится из
определений сервисов; исключение всех `.ru`/`.рф`/`.su` и GeoIP — отдельные режимы.
Общий IP нескольких сайтов не позволяет молча вывести их все из обхода.

## Открытая приёмка

Потеря непрерывности наблюдения `event-drain`, автоматическая цепочка отказов
и установка обновлений без участия пользователя остаются открытыми задачами.
Патч интерфейса их не закрывает. Запланированные сценарии не считаются пройденными
тестами; аппаратные результаты ARM64 не переносятся на MIPS/MIPSel.

Цели Entware сохранены: AArch64 (`aarch64-k3.10`), MIPS (`mipssf-k3.4`) и
MIPSel (`mipselsf-k3.4`). OpenWrt — отдельное будущее направление.

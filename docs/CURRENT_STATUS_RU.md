# Текущий статус RAZVILKA

Обновлено 19 сентября 2026 года. **Выпуск 0.18.2 подготовлен на основе EXT5;
публикация — после завершения проверок на роутере.** Пока опубликованным
стабильным выпуском остаётся
[v0.18.0](https://github.com/ArtixSx/RAZVILKA/releases/tag/v0.18.0).

## Что добавлено и исправлено

- Мастер сервисов, устройств и разрешений Автопилота, проверки по расписанию,
  подписки и разрешённый резерв подключений.
- Каналы обновления приложения, подготовка архива и ручная установка.
- Режимы NFQWS2, импорт доменных списков и настройка компонентов обхода.
- Локальный экспорт одного совместимого подключения для Mihomo,
  экспериментальный профиль HEV и ручные пакеты стратегий NFQWS2.
- Исправления загрузки панели, редактирования NFQWS2, сохранения настроек,
  выбранного набора мастера, сессии входа и импорта файлов.
- Исправления преобразования профилей, подписей пакетов, очереди проверок
  и сохранения ошибок очистки.

## Что подтверждено

Результаты ниже относятся к ревизии
[`a5df27d`](https://github.com/ArtixSx/RAZVILKA/commit/a5df27d).

| Проверка | Результат |
| --- | --- |
| Полный Linux CI | Пройден: Go-тесты, race, vet, 34 набора JavaScript, четыре кросс-сборки и изолированная проверка установщика |
| Реальный изолированный HTTP-сервер | Пройдены 87 проверок |
| Браузер | Проверены настольный и мобильный интерфейсы |
| Чистый Entware на Netcraze ARM64 | Проверенная сборка установлена; вход `admin` подтверждён |
| Состояние панели после установки | Safe Mode включён; выбранных и применённых сервисов нет |
| Маршруты и policy rules | Успешно прочитаны до и после установки; точное совпадение |
| Интерфейс на роутере | Проверены панель и понятный предпросмотр Mihomo |

[Запуск Linux CI](https://github.com/ArtixSx/RAZVILKA/actions/runs/35462661791).

Установка проверялась **без перезагрузки роутера** и без применения маршрутов.
Сравнение firewall пока не выполнено: в чистой Entware отсутствовали
`iptables-save` и `ip6tables-save`; обе попытки завершились кодом 127.
Совпадение таких ошибок не считается успешной проверкой firewall.

## Что проверяется дальше

Исправление автоматического запуска штатного Sing-box при установке пакета
и реальные проверки VLESS/маршрутов на роутере ещё выполняются. Их успех здесь
не заявлен. Итоговая сборка 0.18.2 после этих изменений должна получить
собственные результаты; результаты `a5df27d` не переносятся на неё автоматически.

Mihomo и HEV пока не являются готовыми управляемыми обходами: конфигуратор
не подтверждает запуск и доступность сервиса. Ночная автоматическая установка
полного комплекта с откатом, онлайн-обновление подписанных стратегий и DNS
для конкретного сервиса/устройства остаются отдельными задачами.

Переключение VLESS A/B, WAN reconnect, reboot, физический второй LAN-клиент,
IPv6/UDP, работа на MIPS с ограниченной памятью и длительная устойчивость
требуют отдельных подтверждений.

## Публикация

Семь прежних тестовых записей удалены из Releases: `0.18.1-rc.1`,
`0.18.1-rc.2` и `0.18.2-rc.2`–`rc.6`. Git-теги, история исходников
и стабильные выпуски сохранены.

Для 0.18.2 готовятся архивы ARM64, MIPS, MIPSel и amd64 с контрольными суммами.
Описание выпуска содержит добавления и исправления; подробные результаты
остаются в аудите. Публикация будет отражена здесь после завершения проверки.

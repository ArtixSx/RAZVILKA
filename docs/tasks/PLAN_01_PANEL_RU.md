# 01.1 — Сохранённое состояние панели во время фоновой операции

Ветка: `work/plan-01-panel`. Полный этап: U1, с сохранением регрессий U0.
Сначала прочитать [правила чатов](../CHAT_WORKFLOW_RU.md).

## Первый результат

Панель сохраняет понятное представление настроек автопилота, когда backend
возвращает пригодный сохранённый снимок. При этом она явно показывает возраст
и отсутствие свежего подтверждения; опасные действия не становятся доступными.

На базе 0.18.13 в `console-autonomy.js` после события `razvilka:autonomy-state`
для `retained` отправляется `razvilka:autonomy-error`. В `console.js` обработчик
ошибки затем меняет общую доступность автопилота. Это исходная гипотеза для
воспроизведения, а не готовый вывод о всех случаях.

Проверить цепочку от ответа `/api/v1/panel/autonomy` до главной и автопилота;
исправить подтверждённый дефект минимально. Не переписывать весь интерфейс
и не менять серверную очередь. Обновление общей кнопкой из 0.18.13 сохранить.

## Разрешённая область

`cmd/razvilka/web/console-autonomy.js`, `console.js`, необходимые соседние
UI-модели, `internal/app/panel_*.go` и соответствующие Go/JS-проверки.
По возможности сохранить схему API и ограничиться корректным представлением.
`operations.go`, `reconciler*.go`, `durable_*.go`, `autonomy_worker.go`
принадлежат другому чату. Общий `app.go` требует согласования.

## Проверка результата

- `available → retained → available`: настройки не исчезают, возраст виден,
  новый успешный ответ снимает предупреждение.
- Retained/истёкший снимок не даёт нового proof и не разрешает mutating-действия,
  которые требуют свежего состояния. Ранее разрешённый сервером Stop сохраняет
  собственные проверки, а не получает blanket-разрешение.
- Ошибка одного запроса не превращает все компоненты в «не установлены».
- 401/logout очищают приватное состояние; поздний ответ и старый экземпляр
  сервера не возвращают данные. 404 отличается от временной ошибки наблюдения.
- Сохраняются незавершённые поля и объединение одновременных запросов.
- Целевые регрессионные тесты, проверка синтаксиса JS и сборки интерфейса;
  по возможности браузер с настоящим локальным HTTP backend.

Локальный порт — `18841`. Роутер не изменять; итоговую аппаратную проверку
проведёт основной чат. Если дефект не воспроизвёлся, сохранить доказательства
и точную оставшуюся гипотезу вместо косметического изменения ради коммита.

# Установка RAZVILKA на Keenetic и Netcraze

[Короткая инструкция](../README.md) · [Документация](README.md)

> Инструкция для **0.20.0 Test (`0.20.0-rc.73`)**: чистая установка на Entware
> без установленной RAZVILKA. Переход с 0.19.x не поддерживается; для перехода
> между тестовыми сборками смотрите примечания к нужному выпуску.
> Ограничения — в
> [примечаниях к тестовому выпуску](https://github.com/ArtixSx/RAZVILKA/releases/tag/v0.20.0-rc.73).

## Подготовка Entware

RAZVILKA устанавливается **поверх готового Entware**. Установщик приложения
не форматирует накопитель, не меняет прошивку и не выбирает раздел диска за вас.

1. Включите поддержку открытых пакетов OPKG в компонентах прошивки.
2. Подготовьте накопитель и установите Entware для архитектуры своей модели.
   Для USB-накопителя используйте поддерживаемую прошивкой файловую систему EXT4.
   Внутреннее хранилище доступно только на поддерживающих его моделях.
3. Убедитесь, что Entware смонтирован в `/opt`, и подключитесь по SSH именно
   к оболочке Entware от `root`. Команды ниже не предназначены для консоли
   настройки прошивки с приглашением `(config)>`.

Подготовка диска и установка Entware описаны в руководствах производителя:
[на USB-накопитель](https://support.netcraze.ru/giga/nc-1012/ru/20980-installing-the-entware-repository-on-a-usb-drive.html),
[во внутреннюю память](https://support.netcraze.ru/ultra/nc-1812/ru/18482-installing-opkg-entware-in-the-router-s-internal-memory.html).
Выбирайте в руководстве свою модель. Форматирование удаляет данные выбранного
раздела, поэтому сначала сохраните нужные файлы.

| CPU / Entware | Официальный установщик Entware | Сборка RAZVILKA |
| --- | --- | --- |
| AArch64, `aarch64-k3.10` | [aarch64-installer.tar.gz](https://bin.entware.net/aarch64-k3.10/installer/aarch64-installer.tar.gz) | `razvilka-linux-arm64` |
| MIPS, `mipssf-k3.4` | [mips-installer.tar.gz](https://bin.entware.net/mipssf-k3.4/installer/mips-installer.tar.gz) | `razvilka-linux-mips` |
| MIPSel, `mipselsf-k3.4` | [mipsel-installer.tar.gz](https://bin.entware.net/mipselsf-k3.4/installer/mipsel-installer.tar.gz) | `razvilka-linux-mipsle` |

`mips` и `mipsel` различаются порядком байтов. Обе сборки RAZVILKA используют
soft-float. Установщик различает их по ELF-заголовку оболочки, поскольку `uname -m`
может показывать `mips` в обоих случаях. Выбирать бинарник вручную обычно не нужно.
Сборка `amd64` предназначена для разработки и испытаний; это не четвёртый вариант
Entware для перечисленных роутеров. Матрица Entware: [официальная Wiki](https://github.com/Entware/Entware/wiki).

Быстрая проверка готовности:

```sh
export PATH=/opt/sbin:/opt/bin:/opt/usr/sbin:/opt/usr/bin:$PATH
test -d /opt && command -v opkg
uname -m
opkg print-architecture
df -h /opt
```

Если `opkg` не найден, завершите настройку Entware. Если появляется только
приглашение `(config)>`, это другая консоль — подключитесь к SSH-серверу Entware.

## Установка

```sh
export PATH=/opt/sbin:/opt/bin:/opt/usr/sbin:/opt/usr/bin:$PATH
opkg update && opkg install curl wget-ssl ca-certificates ca-bundle
```

```sh
mkdir -p /opt/tmp &&
curl -fsSL --retry 2 -o /opt/tmp/razvilka-setup.sh \
  https://raw.githubusercontent.com/ArtixSx/RAZVILKA/v0.20.0-rc.73/scripts/bootstrap.sh &&
RAZVILKA_VERSION=v0.20.0-rc.73 sh /opt/tmp/razvilka-setup.sh
```

Скрипт сначала полностью скачивается; он запускается только при успешной загрузке.
Команда закрепляет bootstrap и архив на одном выпуске `v0.20.0-rc.73`; явный
`RAZVILKA_VERSION` обязателен: по умолчанию bootstrap выберет стабильный выпуск.
Далее установщик проверяет инструменты, получает выбранный архив из GitHub Releases,
сверяет SHA256 и вызывает установщик из этого архива. Само приложение устанавливается
без автоматического запуска всех движков обхода.

После установки откройте `http://<LAN-адрес-роутера>:8787`. Для создания учётной
записи введите ключ первого входа, который вывел установщик, либо перейдите по
выведенной им ссылке настройки. Затем настройте нужные сервисы.
Общего пароля, зашитого в дистрибутив, нет.
При обновлении существующая учётная запись сохраняется.

Настройки и подключения хранятся в `/opt/etc/razvilka`. У чистой установки
0.20+ приватные рабочие каталоги находятся в `/opt/razvilka`:

| Назначение | Путь |
| --- | --- |
| Состояние, копии и журналы обновлений компонентов | `/opt/razvilka/state`, компоненты — `state/components` |
| PID панели | `/opt/razvilka/run/razvilka.pid` |
| Кэш | `/opt/razvilka/cache` |
| Журнал службы | `/opt/razvilka/log/server.log` |
| Снимки установки и обновлений | `/opt/razvilka/state/update-backups` |

Приватные каталоги создаются от `root` с правами `0700`. Установщик не меняет
владельца и права общих каталогов Entware, включая `/opt/var`.

Перед загрузкой настроек панель и команда `-recover-private-restore` проходят
проверку сохранённых приватных журналов. На открытие и recovery всей цепочки
из четырёх поколений журнала выделено 120 секунд общего контекстного бюджета.
Медленный `fsync` на накопителе может задержать возврат
дольше этого срока. Истечение бюджета оставляет защитный отказ и сохранённые
журналы; оно не подтверждает восстановление или готовность панели. Не удаляйте
журналы и lock-файлы для обхода ошибки `journal-recover-deadline`.

## Какие утилиты нужны

### Если не определяется MIPS/MIPSel

`uname -m` может показать `mips` на обеих платформах. В исправленном установщике
порядок байтов читается способом, совместимым с компактным BusyBox в Entware.
Устанавливать полный набор GNU-утилит ради этого не требуется.

Если используете старый выпуск и уже знаете архитектуру своего Entware,
скачайте установщик как описано выше и запустите его с явным выбором:

```sh
# Для Entware mipselsf-k3.4 (MIPSel)
RAZVILKA_VERSION=v0.20.0-rc.73 RAZVILKA_ARCH=mipsle sh /opt/tmp/razvilka-setup.sh
```

Для `mipssf-k3.4` укажите `RAZVILKA_ARCH=mips`, для `aarch64-k3.10` —
`RAZVILKA_ARCH=arm64`. Обозначение `mipsel` тоже принимается и означает `mipsle`.
Переменная ставится перед **sh**, который запускает установщик. Если поставить
её перед `curl` в команде `curl … | sh`, она не передастся установщику.

### Список пакетов

Наличие перечисленных пакетов проверено 20 сентября 2026 года в официальных
репозиториях [AArch64](https://bin.entware.net/aarch64-k3.10/Packages.html),
[MIPS](https://bin.entware.net/mipssf-k3.4/Packages.html) и
[MIPSel](https://bin.entware.net/mipselsf-k3.4/Packages.html).

| Пакет / инструмент | Зачем нужен |
| --- | --- |
| `curl` | HTTPS-загрузка установщика, выпусков и проверка HTTP |
| `wget-ssl` | Загрузка HTTPS-каталогов через `opkg`, включая NFQWS2 и WARP |
| `ca-certificates`, `ca-bundle` | Проверка сертификатов HTTPS |
| `coreutils-sha256sum` | Сверка контрольных сумм |
| `tar`, `gzip` | Распаковка выпуска и снимки для отката |
| `coreutils-mktemp`, `coreutils-readlink` | Временные каталоги и проверка путей |
| `coreutils-timeout` | Ограничение времени служебных проверок установщика (`timeout -k`) |
| `busybox` | Базовые команды Entware, включая `start-stop-daemon` |
| `ip-full` | Состояние интерфейсов и работа с таблицами маршрутов |
| `iptables` | Правила маршрутизации для поддерживаемых обходов |

Bootstrap сам подготавливает недостающие базовые инструменты. Для ручной
подготовки окружения:

```sh
opkg update && opkg install curl wget-ssl ca-certificates ca-bundle coreutils-sha256sum coreutils-mktemp coreutils-readlink coreutils-timeout tar gzip busybox ip-full
```

Если нужен обход с правилами iptables и инструмент отсутствует:

```sh
opkg install iptables
```

Не выполняйте `opkg upgrade` всех пакетов ради обновления RAZVILKA. Зависимости
движков и функции ядра проверяются отдельно: установка `iptables` не добавляет
в прошивку отсутствующие модули ядра. `nano`, `htop`, `bash`, Python и компилятор
Go для работы панели не обязательны.

## Обновление

Обновление на этот Test с 0.19.x или другой RC не поддерживается. Сохраните
нужные настройки и подключения, удалите прежнюю установку способом для её версии
и установите Test начисто. Архив старых данных не является пакетом автоматического
импорта; не переносите журналы управления в новую установку.

Обычный стабильный канал обновлений пропускает предварительные выпуски.
Явно выбранный тестовый канал может предлагать RC, но это не подтверждает
возможность обновления установленной RC на этот выпуск.

Bootstrap и ручная установка из архива предназначены для новой установки. На уже
установленной 0.20+ установщик откажет («Use matching self update recovery…» или
«This controller requires the journaled self update workflow…») и ничего не изменит:
прямая замена программы обошла бы журнал обновления и его откат.
Механизм журналируемого обновления и отката требует отдельной приёмки для пары
версий. Не заменяйте бинарник вручную и не удаляйте control/journals ради установки.

## Ручная установка из архива

Скачайте `RAZVILKA-<версия>-entware.tar.gz` и соответствующий файл
`RAZVILKA-<версия>.SHA256SUMS` из одного выпуска. Сверьте SHA256 нужного архива,
распакуйте его и перейдите в распакованный каталог `RAZVILKA-<версия>`.

```sh
sh scripts/upgrade-entware.sh --dry-run
sh scripts/upgrade-entware.sh --apply
```

Запускайте вторую команду после успешной предварительной проверки. Установщик
также проверит `dist/SHA256SUMS`; не удаляйте этот файл из дистрибутива.

## Удаление и откат

**Удаление панели с архивированием данных** выполняется отдельно от отката.
Сначала сохраните нужные настройки и подключения:

Команда ниже — для установленной `0.20.0-rc.73`. Для другой версии используйте
bootstrap и явный `RAZVILKA_VERSION` из её выпуска.

```sh
mkdir -p /opt/tmp &&
curl -fsSL --retry 2 -o /opt/tmp/razvilka-setup.sh \
  https://raw.githubusercontent.com/ArtixSx/RAZVILKA/v0.20.0-rc.73/scripts/bootstrap.sh &&
RAZVILKA_VERSION=v0.20.0-rc.73 sh /opt/tmp/razvilka-setup.sh --uninstall --purge
```

Скрипт останавливает панель, убирает её собственные активные маршруты, бинарник
и автозапуск. С `--purge` все данные RAZVILKA (`/opt/etc/razvilka`,
`/opt/razvilka`, а также старый `/opt/var/lib/razvilka`) **переносятся** в новую
папку `/opt/razvilka-removed-<дата>` с доступом только для `root` — ничего не
стирается. Entware, чужие службы и установленные пакеты обходов сохраняются.
Если перенос остановился, повторите ту же команду. Для чистой установки после
переноса запустите `sh /opt/tmp/razvilka-setup.sh` и настройте панель заново.
Архив сохраняет исходные данные, но не является пакетом автоматического импорта:
не копируйте старые журналы управления и состояния маршрутов в новую установку.
Ненужную папку `razvilka-removed-*` можно удалить вручную позже.

**Без `--purge` управляемая установка 0.20 не удаляется.** Переустановка поверх
сохранённых данных пока не поддерживается. Скрипт обнаружит журнал управления
обновлениями до остановки панели и оставит панель, настройки и подключения на
месте. Не удаляйте журнал вручную. Для обычных обновлений используйте панель.
Удаление без переноса данных остаётся доступным только установкам без этого
протокола управления.

**Откат обновления 0.20+** выполняет панель: если новая версия не прошла
проверку после установки, прежняя версия и настройки возвращаются автоматически,
а состояние показывается в разделе «Обновления». Команды ниже относятся к
установкам, обновлённым установщиком из архива; на установленной 0.20+ установщик
откажет так же, как при обновлении, и ничего не изменит.

**Откат установщиком** возвращает сохранённый снимок:

```sh
sh /opt/tmp/razvilka-setup.sh --rollback
```

Эта команда требует ранее скачанного актуального bootstrap, установленной панели
и доступного снимка. После удаления панели откат недоступен.
Откат может вернуть прежнюю версию панели; это не удаление приложения.
При ручной работе из распакованного выпуска:

```sh
sh scripts/rollback-entware.sh /opt/razvilka/state/update-backups/<снимок>
```

Подставьте путь, который вывел установщик. Не удаляйте вручную весь `/opt`:
там находятся Entware и другие приложения.

## Переход с 0.19.3 и более ранних версий

0.20.0 — новая база: старые настройки, маршруты и журналы не переносятся.
Установщик 0.20 откажет, если найдёт старую установку
(`/opt/var/lib/razvilka` или программу без журнала обновлений 0.20).

1. Узнайте версию: `/opt/bin/razvilka -version`.
2. Удалите её деинсталлятором 0.19.3 — ссылка закреплена за исходным коммитом
   и использует уже установленную программу. Старые теги и Releases не нужны.
   Только он знает, где записаны маршруты старой версии:

   ```sh
   mkdir -p /opt/tmp &&
   curl -fsSL --retry 2 -o /opt/tmp/razvilka-old-uninstall.sh \
     https://raw.githubusercontent.com/ArtixSx/RAZVILKA/817783493f0c2784ccc70aa73868cd64e9437634/scripts/uninstall-entware.sh &&
   sh /opt/tmp/razvilka-old-uninstall.sh
   ```

   Он останавливает панель, убирает её маршруты и удаляет программу, сохраняя
   данные. Если он сообщит об ошибке, не удаляйте программу вручную — её маршруты
   останутся без владельца; напишите в [Telegram](https://t.me/RAZVILKA_UI).
3. Отложите старые данные (они не нужны 0.20 и мешают чистой установке):

   ```sh
   (
     set -eu
     D=/opt/razvilka-0.19-backup-$(date -u +%Y%m%dT%H%M%SZ)
     mkdir -m 700 "$D"
     if [ -e /opt/var/lib/razvilka ]; then
       mv /opt/var/lib/razvilka "$D/state"
     fi
     if [ -e /opt/etc/razvilka ]; then
       mv /opt/etc/razvilka "$D/settings"
     fi
     ls -ld "$D"
   )
   ```

4. Установите 0.20.0 по [обычной инструкции](#установка). Подключения и
   сервисы добавьте заново в мастере; старые ссылки узлов можно взять из
   отложенной папки.

## Если панель не открывается

```sh
/opt/etc/init.d/S99razvilka status
/opt/etc/init.d/S99razvilka lan-ip
/opt/bin/razvilka -version
```

Проверьте, что используется LAN-адрес этого роутера и порт `8787`. При ошибке
HTTPS-загрузки проверьте часы роутера и пакеты сертификатов. Если недоступен GitHub,
воспользуйтесь ручной установкой из проверенного архива. Не отключайте проверку TLS
в установочной команде.

## Если каталоги пакетов не обновляются

Сообщение `wget: not an http or ftp url` для адреса `https://` означает, что
`opkg` использует загрузчик без HTTPS. Это возможно после новой установки Entware.
Когда основной каталог Entware уже получен, установите HTTPS-загрузчик и повторите
обновление:

```sh
export PATH=/opt/sbin:/opt/bin:/opt/usr/sbin:/opt/usr/bin:$PATH
opkg install wget-ssl ca-certificates ca-bundle && opkg update
```

Затем повторите подготовку утилит и установку панели. Если пакет не найден, сначала
проверьте доступность основного каталога Entware. Текущий установщик тоже распознаёт
эту ситуацию: добавляет `wget-ssl` и повторяет загрузку каталогов. В панели нажмите
«Проверить версии»; успешная проверка уберёт отметку об устаревших данных.

## Границы поддержки

Три архитектуры выше остаются обязательными целями сборки проекта. Реальное
испытание на ARM64 и результаты сборок MIPS/MIPSel перечисляются отдельно в
[статусе](CURRENT_STATUS_RU.md). Работоспособность конкретного обхода зависит
от прошивки, движка, профиля и сети провайдера.

Текущий запуск управляемого режима списков (managed LIST) через NFQWS2, Xray
и WireGuard привязан к конкретному проверенному штатному профилю NC-1812.
На других ARM64, MIPS и MIPSel этот запуск сейчас отказывает как недоступный.
Сама установка или работа панели не подтверждает работу режима списков.
Подробности и оставшаяся работа — в [матрице поддержки запуска](RUNTIME_SUPPORT_RU.md).

OpenWrt пока рассматривается как будущая отдельная платформа. Текущие команды
не устанавливают пакет OpenWrt и не настраивают `procd`, UCI или `firewall4`.

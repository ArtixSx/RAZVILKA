# N0.2 — частичный импорт публичных профилей

Локальная разработка, 4 сентября 2026. Не опубликовано и не установлено на роутер.

## Что изменено

- URI-списки, Base64, JSON и Clash YAML разбираются по записям. Поддерживаемые
  узлы сохраняются; отклонённые получают индекс, фиксированный код и причину.
  Исходная ссылка, имя и credentials отклонённой записи в отчёт не попадают.
- Одинаковые нормализованные узлы без учёта отображаемого имени объединяются.
  Разные credentials остаются разными узлами. Digest используется только в памяти.
- `source_index` и индекс ошибки начинаются с 1. Для текста это номер непустой
  записи без комментариев, для JSON/YAML — позиция в массиве. `selected_index`
  по-прежнему начинается с 0 и относится только к принятым узлам.
- Повреждение внешнего JSON/YAML, повторные JSON-ключи, превышение лимита
  или отсутствие принятых узлов блокируют весь импорт. Старый черновик сохраняется.
- API возвращает безопасный `preview` и при полном отказе. Смешанный список
  нельзя сохранить без `accept_partial: true`: ответ 428 с кодом
  `PARTIAL_IMPORT_CONFIRMATION_REQUIRED`, без записи файлов.
- UI показывает «Принято», причины отказов/пропусков под раскрывающимся блоком
  и кнопку «Создать черновик из N принятых». Она сама является подтверждением:
  дополнительного окна нет. Изменение исходного текста требует нового preview;
  запоздавший ответ и двойной клик не запускают импорт.

Это ограниченный in-memory карантин на время предпросмотра, **не** постоянный
NodeStore/retry queue. Отклонённые исходники не сохраняются для будущего повторного
разбора. Подписки, расписание, XHTTP и активация community routes не добавлены.
Проверка формата не доказывает доступность узла или сервиса.

## Проверки

- Полный `go test ./...`, `go vet ./...` и UI behavior scripts прошли на Windows.
- Синтаксис `app.js` и `git diff --check` проверены.
- Смешанные URI/Base64/native JSON/Clash, индексы и выбор после отказов.
- Дубликаты с разными именами; сохранение узлов с разными credentials.
- Отсутствие отклонённых credentials в preview и сгенерированном конфиге.
- Полностью ошибочные и повреждённые пакеты не создают конфиг.
- API: отказ без согласия на частичный импорт не меняет старый черновик;
  согласованный импорт сохраняет только принятые узлы.
- UI behavior: отклонённые записи экранированы, частичная кнопка передаёт
  согласие, редактирование/двойной клик/запоздавший preview безопасны.
- Свежая ограниченная выборка публичных источников: VLESS Checker 16 принятых;
  Goida 12 принятых и 4 отклонённых с INVALID_PARAMETERS. Только разбор в памяти,
  без подключения к прокси и сохранения ключей. Не оценка всех списков.

Нужны Linux/race, визуальная проверка браузера и аппаратные gates перед стабильным
релизом. Роутер и рабочие маршруты не изменялись. Формат persistent storage не меняется.

см. [публичные источники и автоматика](PUBLIC_PROVIDER_SOURCES_RU.md).

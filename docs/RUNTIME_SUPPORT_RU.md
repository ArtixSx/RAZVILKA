# Поддержка платформ и функций

| Возможность | Результат для rc.128 |
| --- | --- |
| Entware ARM64 | Установка и штатный Stop проверены на NC-1812 |
| MIPS, MIPSel | Бинарники включены в поставку. Аппаратная приёмка для этих процессоров остаётся открытой |
| AMD64 | Есть бинарник для стенда. Автодоставка закреплённой сборки HEV для AMD64 требует отдельного артефакта стабильной версии v0.20.0 |
| Xray / VLESS | На NC-1812 подтверждены получение публичных кандидатов, проверка Telegram Web и сохранение резерва |
| Общая домашняя сеть с исключениями | Применение маршрута ко всей сети требует отдельного доказательства; в испытанном режиме автопилот сообщает о проверенном сервисе и недоступном маршруте для LAN |
| Managed NFQWS2 Apply, экспериментальный DNS, WARP / MASQUE | Сквозная работа в домашнем сценарии этого выпуска не подтверждена |
| Восстановление | После Stop возвращены исходные каталоги, маршруты и выход исключённого компьютера |

Точное различие между резервом и применённым маршрутом приведено в [результатах проверки](CURRENT_STATUS_RU.md).

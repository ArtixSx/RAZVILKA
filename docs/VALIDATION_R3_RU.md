## Что тестировалось в браузере

Одна AI-группа по категории, раздельные маршруты и доказательства, частичная сводка, невыбранные future-участники, поиск скрытого/выключенного сервиса, пользовательская AI-категория, ожидание в очереди, отсутствие побочных mutations при рендеринге, список/карточки, inspector/focus/Escape, фильтр протоколов до пагинации, сохранность dirty-полей, создание/пауза/удаление по прежним API-контрактам, CAS 409, ошибка источника 503 и сохранность каталога, выход/401 и отмена delayed retry, отсутствующий A1 API (404) с запретом сохранения мастера, light/dark и мобильное меню.

Данные, формы ответов и сообщения в отдельном preview тестовые. Fake-транспорт никогда не входит в `cmd/razvilka/web`. Проверки узлов демонстрируют INCONCLUSIVE; реальное применение/установка не выдаются за успех. Никаких подключений к публичным узлам, Cloudflare-регистраций или изменений роутера.

Файл `native-responses.json` унаследован из UI2 как исторический read-only snapshot rc.2. **В этом этапе новый native-прогон не делался.** Он не подтверждает A1/R3. Отказ missingAPI тестируется отдельным fixture, а не новым подключением к установленной rc.2.

## Визуальная проверка

Сохранены 33 актуальных снимка всех разделов, editor-context, AI-раскрытия, инспектора и мобильных состояний. Проверены глазами главная, каталог, редактор NFQWS2, светлая/тёмная тема и ключевые мобильные экраны. Перекрытие меню подложкой и переполнение диагностики исправлены.

Дополнительный эвристический расчёт текстового foreground/background на17 представлениях × 2 темы не нашёл отношения ниже 3:1 у просмотренных активных текстовых элементов. Этот ограниченный расчёт не учитывает все gradients/opacity/изображения/состояния и **не является WCAG-аудитом**. Порог AA для обычного текста выше. Нет заявления о сертификации доступности или screen-reader/WebKit/Firefox поддержке.

## Окружение

Python 3.13, Playwright 1.57.0, системный Chromium, Node 22.16.0, Go 1.23.2. HTML передавался локально через `set_content`, без нового Go HTTP-сервера. Шрифты системные; внешний CDN не загружается. Версия Go 1.26.5, требуемая go.mod, здесь недоступна; download ранее не удался. Production-версии и зависимости не снижались.

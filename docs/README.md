Проверки конкретной ревизии относятся только к ней. Поддержка сборки для
архитектуры и испытание на физическом роутере отмечаются отдельно в статусе.

**OpenWrt** — возможное отдельное направление развития. Текущий установщик
рассчитан на Entware с каталогом `/opt` и автозапуском Keenetic / Netcraze;
готового пакета OpenWrt и интеграции с его `procd`, UCI и firewall пока нет.

Текущий статус описывает проверенные возможности, план — будущую работу,
архив — историю. Проверка конкретной ревизии относится только к ней:
сборка под архитектуру и испытание на физическом роутере отмечаются отдельно.

**OpenWrt** — отдельное возможное направление развития. Текущий установщик
рассчитан на Entware с каталогом `/opt` и автозапуском Keenetic / Netcraze.
Готового пакета OpenWrt и интеграции с `procd`, UCI и firewall пока нет.

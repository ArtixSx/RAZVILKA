## Первая задача координатора

Работать в отдельной ветке/копии. При более новом checkout перенести diff и сохранить изменения владельца — не reset и не перезапись всей рабочей папки.

```sh
git status --short
cat VERSION
cat go.mod
go version
go mod verify
sh scripts/check.sh
```

Нужен штатный Go 1.26.5 (go directive 1.26.0). В подготовившей пакет среде был Go 1.23.2, загрузка toolchain блокировалась DNS/сетью. Полный Go CI, сборка бинарников и запуск реальных движков **не выполнены**. Проверки отдельных файлов в временном go1.23-модуле не заменяют этот gate. Не понижать production go.mod ради зелёного результата.

## Цель не изменилась

RAZVILKA применяет обходы только к активному списку сервисов, доменов и поддержанных IP/CIDR-правил, по смыслу user list. Список действует на выбранные домашние сети без обязательного назначения каждого сервиса каждому устройству. Исключённые устройства и ресурсы из действующего списка исключений сервисов не обрабатываются обходами RAZVILKA. Список исключений объединяет отдельно хранимые ручные записи и разрешённый обновляемый каталог российских ресурсов. Несовпавший трафик использует обычную политику роутера. Пустой активный список не создаёт обходов. Общее подключение может обслуживать несколько активных записей, но не становится туннелем для остального интернета. Нужны общий исполнитель и согласованный DNS; защиту неподдержанного исполнения нельзя удалять вместо реализации.

Актуальное уточнение владельца от 07.10.2026: [контракт списков и исключений](docs/delivery-2026-10-03/LIST_MODE_CORRECTION_RU.md). Оно заменяет прежний охват «весь интернет», сохраняя порядок D00–D14 и результаты проверок.

Вход на страницу — разрешение пользоваться интерфейсом, **не команда менять сеть**. Обычные параметры можно редактировать без дополнительного «unlock»-режима. Новый охват, публичный провайдер, удаление и неизвестный откат по-прежнему требуют корректных полномочий. Recovery fence/Safe Mode восстановления, Stop, auth, CSRF, ownership, TLS, CAS и rollback не отключать.

Следующая рабочая вертикаль: точный VLESS/Xray → Generic WG → AWG. Проверки и UI могут улучшаться параллельно, но только один автор меняет каждый общий файл.

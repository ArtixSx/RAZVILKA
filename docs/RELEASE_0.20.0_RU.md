# RAZVILKA 0.20.0 — проект примечаний к выпуску

Локальный текст для review перед публикацией. Тег `v0.20.0` и его assets должны
быть опубликованы координатором после итоговой проверки. Этот документ сам по
себе не означает готовность выпуска или аппаратный PASS.

## Что меняется для пользователя

- Локальная панель сервисов, подключений и устройств; простой и расширенный виды.
- Раздельные сохранённые настройки, применённый маршрут и подтверждённый доступ.
  Последний сохранённый снимок обозначается как состояние без свежего ответа.
- Импорт поддержанных профилей и подписок, проверки выбранного пути,
  управляемые операции и сохранение журналов при неизвестном результате.
- Чистая база 0.20.0; будущие обновления — только на семантически более высокую
  версию через штатный журналируемый процесс. Миграция ≤0.19.3 не входит в выпуск.

## Установка и ограничения

[Команды установки и удаления](../README.md#установка),
[подробная инструкция](INSTALL_RU.md), [матрица платформ](RUNTIME_SUPPORT_RU.md).
Три router targets: ARM64, MIPS, MIPSel; AMD64 — Linux-стенд. Managed LIST требует
точного поддержанного профиля. Сборки MIPS/MIPSel не означают физическую проверку.
Автопилот и обновления действуют только при разрешениях и успешных проверках;
запущенная панель не доказывает доступ с клиента.

Удаление сохраняет настройки, подключения, снимки и контрольный журнал;
Entware и чужие пакеты остаются. Повторная чистая установка поверх сохранённого
контрольного журнала пока отказывает. Не удаляйте его вручную для обхода отказа.

## Итоговая приёмка перед выпуском

Окончательный source SHA, asset SHA-256, результат чистой установки, реального
импорта Telegram через UI и часового наблюдения добавляет координатор по своим
журналам. Сейчас здесь **не заявлены** итоговый часовой PASS, полный hardware
PASS или успешный будущий production update/rollback. Источником подробностей
остаётся [текущий статус](CURRENT_STATUS_RU.md); старые Linux fixtures не заменяют
новую проверку на роутере.

После clean-проверки добавить обезличенные снимки главной страницы, подключения
Telegram и диагностики. До этого существующий баннер остаётся иллюстрацией
проекта, а не свидетельством работоспособности. Не включать ключи, токены,
адреса узлов или домашние устройства.

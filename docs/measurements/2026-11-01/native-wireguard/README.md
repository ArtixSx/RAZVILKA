# WireGuard: реальное ядро, 01.11.2026

Источник: isolated validation `dbce66e4677312573a2c7e87896fb3898ae83722`,
[run 41268705364 / job 124736820125](https://github.com/ArtixSx/RAZVILKA/actions/runs/41268705364/job/124736820125).
[Нативный лог](dbce-native-excerpt.log) сохраняет фактические этапы и времена.

На исходном `8522538a` candidate IPv4/IPv6 и правильный endpoint canary
проходили, но Activate возвращал exit2. Реальный `ip -N -4/-6 -j route
show table` для отсутствующей таблицы выдаёт точный ENOENT, `Dump terminated`
и незакрытую `[`; старый разбор не допускал этот вариант диагностики.
Исправление `85c098a4` допускает только независимое полное текстовое чтение
тем же исходным владельцем. Ошибочный JSON сам не подтверждает отсутствие.
Успешный malformed JSON, неправильное семейство, дополнительные данные и
ошибка подтверждения по-прежнему отвергаются.

После исправления прошли:

- Полная свежая проверка неактивности WARP WG, WireGuard и AmneziaWG без
  подмены процессов/команд; обе семьи и все предусмотренные таблицы.
- Настоящий kernel WG candidate для IPv4/IPv6, неверный peer key при
  доступном обычном WAN и последующая проверка правильного peer.
- Endpoint Activate/Health/Commit, WAN pin, новый процесс, другой peer,
  откат к прежнему сервису, частичные записи/cleanup и повтор.
- Реальный LAN TCP/UDP IPv4/IPv6, NAT, исключённый MAC и privacy address,
  исходные receipt, частичные известные/неизвестные эффекты и восстановление.

Последний сценарий требует `br_netfilter`. Модуль загружается только на
одноразовом GitHub runner; сетевые/sysctl изменения теста выполняются в
новых private net/mount/PID namespaces. Сам standalone script не загружает
модуль. Ранний запуск без этого prerequisite честно завершился FAIL.

Это доказательство kernel/receipt composition и adapter lifecycle.
Оно не заменяет полный обычный Core/App managed LIST startup, аппаратную
приёмку, AWG-туннель с настоящим внешним модулем или WAN-сервером.
Единичные времена в логе — длительности fixture, не измерение ускорения.
Production профиль платформы не расширен. Роутер не изменялся.

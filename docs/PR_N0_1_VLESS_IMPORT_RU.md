# PR-N0.1 — строгий импорт VLESS

Дата: 4 сентября 2026 года. База: `777a127`. Локальная разработка.

## Причина и границы

В `internal/providerprofile/uri.go` неизвестный type раньше давал отсутствующий
transport, неизвестный security — отсутствие TLS, а flow копировался без
проверки. Clash терял неизвестный network до построения native outbound.

Этот блок меняет разбор/предпросмотр/отказ импорта. Он не создаёт NodeStore,
не реализует XHTTP, не подключает подписки и не меняет dataplane.
На момент N0.1 ошибочная запись отклоняла весь пакет. Это поведение заменено
[N0.2: частичным импортом](PR_N0_2_PARTIAL_IMPORT_RU.md); строгая проверка каждой
записи и защита существующего черновика сохраняются.

## Контракт

- URI: разрешены TCP, WS/websocket, gRPC, HTTP/h2. Отсутствующий type сохраняет
  прежний TCP default. XHTTP, SplitHTTP и неизвестные значения возвращают
  `UNSUPPORTED_TRANSPORT`, не создавая конфиг.
- Security: none/tls/reality. Flow: пустой либо xtls-rprx-vision только с TCP
  и TLS/Reality. Проверяется packet encoding, явное значение переносится в конфиг.
- Неизвестные query-параметры, повреждённое кодирование, повторные параметры
  и неоднозначные aliases отклоняются. Это консервативный импорт: расширение
  списка параметров требует отдельного mapping и тестов.
- Для VLESS запрещено отключение проверки сертификатов во всех трёх форматах.
  Аналогичная политика HY2/TUIC и экспертного импорта требует отдельного аудита
  и не заявляется завершённой этим блоком.
- Base64/JSON-ссылки используют ту же проверку. Native VLESS JSON и Clash YAML
  проверяются до преобразования. JSON с повторными ключами, лишним документом
  или чрезмерной вложенностью отклоняется.
- Ошибки содержат фиксированный код, но не пользовательские значения. Имя
  YAML-узла исключено из ошибок; известные credentials, повторённые в имени
  или адресе preview, маскируются. Строка URI в имени скрывается.
- API preview/import возвращают HTTP 400, code, error и draft_preserved=true.
  Старый черновик не перезаписывается при отказе.

Это проверка схемы импорта, не доказательство Reality handshake, корректности
всех полей профиля или доступности сервиса. Native validation и canary остаются
обязательными. Поддержка XHTTP в RAZVILKA по-прежнему отсутствует.

## Проверки

- Полный `go test ./...` и `go vet ./...` прошли на Windows.
- Table tests: неизвестные режимы, XHTTP, неоднозначные aliases, кодирование,
  IPv6, поддерживаемые транспорты и сохранение packet encoding.
- Отрицательные JSON/YAML fixtures и Base64-обёртки ошибок.
- Secret canary в ошибке/имени; API-тест сохранения существующего черновика.
- Fuzz транспорта: 20 секунд, 389 501 выполнений, без найденных отказов.
- По отдельному разрешению пользователя проверены живые публичные образцы:
  VLESS Checker — 16/16 разобраны; Goida `githubmirror/26.txt` — 12/16 разобраны,
  4 отклонены с INVALID_PARAMETERS. Не более 16 уникальных ссылок на источник,
  HTTPS через publicfetch, лимит ответа 2 МиБ/20 сек. Ссылки обрабатывались
  только в памяти, не сохранялись в fixtures и не выводились в журнал.
  Это не проверка доступности узлов и не репрезентативная оценка всех подписок.
- Live sample test выключен по умолчанию, требует
  `RAZVILKA_TEST_PUBLIC_PROFILES=1`; обычный CI не обращается к этим feeds.
- Race detector на текущем Windows toolchain не запустился: требуется CGO,
  C-компилятор не настроен. Успешный race-прогон не заявляется.

Роутер не обновлялся. Новый транспорт не добавлен; его аппаратная поддержка
не заявляется. Linux/race и аппаратная матрица релиза остаются отдельными gates.

## Совместимость и откат

Рабочие файлы и старые черновики не мигрируются. Ранее принятые неоднозначные
ссылки теперь могут отклоняться — это ожидаемое исправление. Откат кода:
отдельный revert коммита после проверки дерева. Откат роутера не требуется.

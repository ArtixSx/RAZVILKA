# Автопилот

Для Telegram Web на NC-1812 подтверждены два независимых результата: ошибка первого публичного кандидата и свежий ответ HTML через второй. Ошибка одного запроса переместила узел в конец очереди; запись осталась в инвентаре. Отдельный карантин этим наблюдением не подтверждён.

Результат для домашнего трафика проверяется с устройства в области действия правила. Сохранённый резерв означает успешную проверку с роутера. [Аппаратные результаты](CURRENT_STATUS_RU.md) · [Области поддержки](RUNTIME_SUPPORT_RU.md)

АВТОПИЛОТ

Автоматический выбор без лишних подтверждений

Текущий рабочий путь сохраняется. Смена выполняется только после подтверждённого отказа или явного преимущества другого установленного обхода; при ошибке действует автоматический откат.

Последние результаты

«Работает» означает, что сервис действительно ответил. «Частично» — сеть доступна, но сервис вернул ограничение авторизации, региона или политики. Автовыбор учитывает только подтверждённые маршруты.

3 УСПЕШНЫЕ ПРОВЕРКИ
Безопасная границаRAZVILKA запрещает опасные системные параметры и команды. Победившая стратегия сначала сохраняется как обычный черновик, проверяется и получает резервную копию.
Ресурсы тестаПроверяем RAM и нагрузку роутера…
Проверка внешнего источника…Только чтение совместимых стратегий NFQWS2
Цель изолированного тестаURL берётся только из каталога сервисов. Во время теста создаётся временная точечная NFQUEUE для одного IP и source-port; после запроса она удаляется.

Кандидаты

Неизвестные параметры сохраняются, но пригодность определяет сам установленный NFQWS2.

Новый кандидат

Можно вставить многострочную стратегию и комментарии. Командные подстановки запрещены.

Воспроизводимость

Выбор доступен только после трёх свежих подтверждённых проходов по одинаковому сервису, протоколу и IP-семейству. Старые результаты постепенно теряют вес; QUIC никогда не наследует результат TCP.

Память рабочих стратегий

Запомненный вариант остаётся черновиком. После трёх последовательных изолированных отказов RAZVILKA вернётся к другому свежему подтверждённому кандидату; рабочий NFQWS2 здесь не переключается.

    Использовать группу

    Сначала выбор сохраняется в настройках сервиса. Примените изменения, чтобы включить резерв.

    Автоподбор

    Работает на роутере при закрытом браузере. Проверенный текущий узел сохраняется; замена выбирается при подтверждённом отказе.

    Разрешённые подключения

    Разрешение распространяется только на отмеченные подключения и указанные источники. Новые узлы из обновлённой подписки не добавляются в резерв автоматически. Проверяется веб-доступ; при отсутствии рабочего резерва маршрут сохраняется, а панель сообщает о сбое.
